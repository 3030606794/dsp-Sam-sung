# dsp音效

一个 APK、一个 Magisk 驱动，整合 170 段参数均衡器、JamesDSP、ViPER RE 和十项 MSEB 听感调音。当前版本为 **0.1.0-alpha9**，Android 8+，ARM64/ARMv7，需 root。应用包名和签名保持不变，可覆盖升级。

alpha9 让七类滤波器都支持真实增益，优化实时曲线，并增加独立 PEQ 预设收藏、频响图固定/随列表滚动切换、红点定位和批量重置；设置中的步长仅控制加减按钮。驱动协议升级为 5，**必须同时升级 alpha9 APK 和驱动，并重启加载新驱动，不能沿用 alpha7/alpha8 驱动。** 保留 Q 0.1–100、增益 ±100 dB 和独立展开/开关操作。

- 参数均衡器的响应曲线可用右上角按钮切换固定顶部或随列表滚动隐藏，偏好随配置保存；频段列表最多 170 段，保留滚动复用。支持峰值、低架、高架、低通、高通、带阻和带通。
- 每段独立频率、Q 和增益，适用类型支持 Q/BW 编辑。低通、高通、带阻、带通的增益作用于滤波后的输出，不改变频率/Q 形状，0 dB 时仍执行滤波。加减按钮步长可设为增益 0.01–2 dB、Q/BW 0.01–100、频率 1–1000 Hz；拖动滑杆分别按 0.01 dB、0.001、1 Hz 调节。增益范围为 1–100 dB，精调增益输入也限制在当前范围内。
- 曲线左右各留 2dp，线宽 1.25dp。每张频段卡片顶部的“定位频段”按钮会展开图表，并显示该频段红点、频率/增益文字和 XY 定位线 2 秒，不改变参数。拖动时标记持续显示，松手或点动加减后 2 秒隐藏。可打开 Q/BW 和频率滑杆，Q 越大越窄，BW 越大越宽。
- 底栏固定提供设置、预设、添加频段和重置入口。可单独重置 Q、频率、增益或同时重置三项；Q 恢复默认值，频率按现有段数在 20–20000 Hz 对数分布，增益归零，保留段数、滤波类型、启用状态和显示设置。
- “添加频段”和数量增加时的新频段均为峰值、0 Hz、0 dB、Q 0.5。0 Hz 表示频率尚未设置，不参与滤波；设为 20–20000 Hz 的有效频率后才生效。调整数量默认保留已有频率，可从前端或后端增删（默认后端），并可选择将全部频率重新分布到 20 Hz–20 kHz。默认频段组和重置仍保持原有分布与默认 Q。
- 独立 PEQ 预设库最多收藏 20 个，支持保存当前参数、应用、改名、覆盖和删除，以及 UTF-8 JSON 导入、单项或全部导出备份。切换设备或加载全局预设不会替换收藏库；导入先校验全部内容和剩余容量，重名自动加序号而不覆盖。应用收藏不会自动启用音效。格式说明见 [PEQ 预设](docs/PEQ-PRESETS.zh-CN.md)。
- 删除旧曲线/AutoEQ 编辑器、搜索客户端和服务器设置；历史曲线字符串仅保留备份，不再处理。

旧 PEQ JSON schema 1 仍可读取；此前四类通带/阻带滤波器未使用的隐藏增益会迁移为 0 dB，保留升级前的声音，读取时不覆盖原配置。后续保存使用 schema 2，原有设备/全局预设的新导出文件要求应用版本码至少 1009。独立 PEQ 收藏使用 `dsp-audio-peq-presets` version 1 文件格式，不保证直接导入 Neutron 预设。

- 活动设备配置与输出控制合并为顶部固定卡片；左右平衡支持双击归零。
- 底部中央总开关控制整条音效链；删除两个处理段开关和顶部实现说明。
- 删除 ViPER 输出音量/限制器、十段 EQ、扬声器优化的界面、命令和算法，以及 ViPER 重置入口。
- 听感调音显示为 MSEB：左右关键词、左减右加按钮每次一步、Material 滑杆实时调节、双击归零，保留三档范围。
- 所有效果默认折叠，点击标题仅展开/收起，右侧开关独立控制启用；ViPER 拆分独立卡片并配对应图标，复用 DSP 颜色和动画。
- 使用用户提供的 SVG：固定黑色图案、白色背景，无系统主题色图层。
- 保留 JamesDSP 的均衡器、动态低音、压扩器、混响、声场、交叉馈送、VDC、卷积、LiveProg，以及其余 ViPER 效果。

十项听感调音使用独立的滤波与动态模型近似海贝 MSEB 的调节方式，不分发海贝私有算法。参见 [映射说明](native/tone/README.md)。

安装、升级与回退见 [兼容性说明](docs/COMPATIBILITY.zh-CN.md)。每次构建运行应用界面、参数、安装器及原生音频回归，先生成发布草稿；验证结果和实际测试范围记录在 Releases。

## 构建

使用 Java 17、SDK35、NDK26.3.11579264、CMake3.22.1 和仓库 Gradle wrapper：

```sh
./gradlew :app:assembleRootFdroidRelease :app:testRootFdroidReleaseUnitTest
cmake -S native -B build/host -DFUSION_BUILD_TESTS=ON -DCMAKE_BUILD_TYPE=Debug
cmake --build build/host
ctest --test-dir build/host --output-on-failure
```

源码构建保留单个融合库和单个公开音效实例，处理顺序为参数均衡器 → JamesDSP → MSEB → ViPER → 左右平衡。

签名私钥保存在 GitHub Actions Secrets，不提交手机备份、用户 IR 文件或海贝二进制。上游作者、许可证和改动出处见 [第三方说明](docs/THIRD-PARTY.md) 与 [原应用说明](docs/UPSTREAM-APPLICATION-README.md)。
