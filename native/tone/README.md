# DSP Fusion 听感调音 v1

原创 C++ 实现，GPL-3.0-or-later。借鉴海贝 MSEB 的十项听感名称、正负方向和 ±20/±40/±100 操作范围；**没有取得或复用海贝的内部系数、算法源码或闭源音效库，也未完成声音等效测量**。这是可以继续实测校准的听感近似模型，不宣称与海贝逐样本或主观听感一致。

## 已实现映射

`x` 为滑块整数除以 100；小、中、大范围只限制整数取值，不改变同一数值对应的算法力度。缩小范围时把已有值截断到新范围。

| 项目 | x = +1 的处理，负值反向 | 动态行为 |
| --- | --- | --- |
| 总温度 | 180 Hz 低架 +4 dB，3500 Hz 高架 -4 dB | 无 |
| 低音下潜度 | 60 Hz 低架 +6 dB | 无；不合成不存在的超低频 |
| 低音弹性 | 110 Hz、Q 0.8 峰值 +3 dB | 150 Hz 低频起音成分最多 +3 dB，5/70 ms 双包络 |
| 厚度 | 350 Hz、Q 0.75 峰值 +4 dB | 无 |
| 人声 | 1800 Hz、Q 0.8 峰值 +4 dB | 不进行人声分离 |
| 女毒 | 3500 Hz、Q 1.0 峰值 +3 dB | 不进行女声识别 |
| 齿音（低频） | 5500 Hz、Q 1.1 峰值 +4 dB | 普通频段调色，不是动态去齿音 |
| 齿音（高频） | 8500 Hz、Q 1.1 峰值 +4 dB | 同上 |
| 乐器瞬态 | 无固定 EQ | 宽带起音最多 +3 dB，2/45 ms 双包络；负值柔化起音 |
| 空气声 | 12000 Hz 高架 +4 dB | 无 |

搁架坡度 S=1。低采样率下中心频率上限为采样率的 0.43，避免跨越 Nyquist。双声道使用独立滤波状态、共享动态包络，保持左右定位。实现使用十个双二阶滤波器；动态低通为一阶。其“低音弹性”“乐器瞬态”含真实信号相关增益，并非只把 EQ 换名称。

## 余量、平滑与接口

- 对合成滤波曲线进行 193 点采样估算峰值，为正增益及两个动态阶段预留输入增益余量。实际音量可能下降，不能将自动余量理解为响度匹配或严格峰值限幅器；整个链路仍需要驱动的最终保护。
- 系数、输入增益、动态力度、干湿转换以约 20 ms 时间常数平滑。首次创建时全零和关闭状态是逐样本完全旁路；由有声效果退回关闭/全零后先淡出，稳定后恢复精确旁路。重置/采样率切换清除状态。
- 音频回调没有内存分配。控制线程先持有包装器锁，再调用 `setParameters`；本类不自行解决外部并发。
- 参数号 `196608`，44 字节：`int32[11] = {enabled, temperature, bassDepth, bassImpact, thickness, vocal, female, lowSibilance, highSibilance, transient, air}`。原始参数夹紧至 [-100,100]；不正确长度直接拒绝。
- `configure(uint32_t)`、`setParameters(const int32_t*, size_t) -> bool`、`process(float* stereoInterleaved, uint32_t frames)`、`reset()`。
- 应用在 `dsp_fusion_tone.xml` 保存整数参数，沿用 JamesDSP 设备配置和预设打包流程；独立于现有 GraphicEQ/LiveProg 通道，不覆盖原设置。

## 主机测试

```sh
cmake -S native/tone -B build/tone -DCMAKE_BUILD_TYPE=Release
cmake --build build/tone
ctest --test-dir build/tone --output-on-failure
```

测试覆盖 44.1/48/96 kHz：初始全零/关闭逐样本旁路、十项均有效、关键频段正负方向、瞬态起音与稳态差异、超范围输入、错误消息长度、块大小无关、频繁调整、静音/脉冲/非有限输入、关闭后淡出。测试是数值和行为验证，不能代替与用户手机海贝播放器的听感对比。
