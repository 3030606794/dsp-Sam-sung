一、原十项与本轮范围
本轮增强独立的“音色调节”模块，保留原十项：总温度、低频深度、低音弹性、声音厚度、人声、女毒、低齿音、高齿音、乐器瞬态、空气感。
保留原 ±20、±40、±100 三种范围入口、原默认声音、模块电源及开关折叠规则。原十项继续以整数保存，原范围继续以规范 String "20"、"40"、"100" 保存，不迁移成其他单位。
“人声”“女毒”是作用于相应频段的音色宏，不识别或分离人声；“低齿音”“高齿音”是静态频段音色宏，不是自动动态去齿音。本轮不把静态滤波换个名称冒充动态去齿音。
“低音弹性”原本同时包含约 110 Hz 静态隆起和低音起音处理；“乐器瞬态”原本使用快慢包络差控制起音增强或柔化。本轮开放这些真实处理的参数。
专业总开关、核心、频率形状、动态、弱信号保护、干湿、输出、额外余量、电平、静态响应图全部默认关闭；模块默认电源规则不变。
关闭专业模式恢复原十项处理。专业模式开启但所有新增声音分组关闭，使用原十项基础声音，不悄悄套入系统方案。
与模拟谐波染色、模拟音色仿真、动态音色处理、动态范围压扩器和其他模块分别保存、分别处理。多个模块同时打开时仍按原音频链顺序叠加，独立保存不表示最终听感互不影响。

二、核心精调叠加与复位
核心组默认关闭。十项各提供 −200.0–200.0 点的修正，精度 0.1 点；修正量叠加在当下原十项基础上，原整数不被覆盖。
总作用强度 0.0–200.0%，默认 100.0%。有效宏值为：先将“原值＋修正量”限制到 −100–100，再乘总作用强度。强度超过 100% 允许更强的滤波和动态目标，也可能改变余量与音量。
十项修正单项复位为 0.0 点，即回到当前原值；它不是将原整数清零。总强度单项复位为 100.0%。
只有“专业调节＋核心精调”同时开启才接管原十项和原范围，它们变灰并显示接管说明；关闭核心组或专业模式后恢复原十项与范围可调。其他专业组单独开启不接管原十项。
分组关闭时保留专业请求，重新打开恢复。数值支持滑杆、直接输入、加减和单项复位；当前无效或关闭的项置灰，已打开输入框也不能绕过禁用状态继续提交。
有效参数包关闭模块或使用专用仅关电源命令时，立即取消候选预热并清除临时工具，按原 20 ms 一阶时间常数逐步淡到旁路，不等待候选预热结束。关闭专业模式立即恢复原基础处理目标，滤波、干湿、输出与额外余量按原平滑趋近；20 ms 是时间常数，不表示 20 ms 后已经绝对恢复完成。
原三种范围保留原明确切换行为：切到较小范围时，超出新范围的原十项整数按旧规则截到边界。专业核心接管后原范围入口禁用。
新增“局部窗口”仅调整专业修正滑杆的显示范围，不截断、不改写保存值，不改变音频。窗口缩小时，已保存值仍被包含或明确显示；查看、缩放和拖动到提交之前不会改变保存的音色参数。
局部窗口与显示步长属于界面设置，不进入音频包、个人预设、设备配置或声音比较指纹。
原“全部归零”恢复原十项 0、原范围 ±100，同时清除本模块专业修正与分组、临时试听和匹配，保留模块电源及折叠状态；不清空个人收藏或其他模块。

三、作用频率与形状
频率形状组默认关闭。十个滤波位置分别开放 20–20000 Hz 的请求频率，步进 1 Hz。
默认依次为：温度低架 180 Hz、温度高架 3500 Hz、低频深度 60 Hz、弹性静态隆起 110 Hz、厚度 350 Hz、人声 1800 Hz、女毒 3500 Hz、低齿音 5500 Hz、高齿音 8500 Hz、空气感 12000 Hz。
这些是独立滤波位置，不要求十项频率升序。修改频率只改变对应滤波器；对应原宏及修正为 0 时，该滤波器的增益也为 0，仅改频率可能听不出变化。
六个峰值滤波器开放 Q 0.25–4.00，精度 0.01，依次对应弹性静态隆起、厚度、人声、女毒、低齿音、高齿音；默认为 0.80、0.75、0.80、1.00、1.10、1.10。较大 Q 表示更窄的作用区域。
温度低架、温度高架、低频深度、空气感开放架式坡度 S 0.250–1.000，精度 0.001，默认 1.000。S 是所用架式滤波公式的形状参数，不标为固定 dB/oct 斜率。
温度低频与高频权重分别为 0.0–200.0%，默认各 100.0%；原温度正值增强低频、衰减高频，负值方向相反，两端可分别控制。
频率、Q、坡度、权重复位回原算法对应值，不把当前原十项宏清零。关闭形状组恢复原频率、Q、坡度和两端比例。
请求频率保留原值，驱动按实际处理采样率采用不超过 0.43×采样率的安全频率；采样率恢复后重新派生实际值，不永久覆盖保存请求。状态显示实际作用频率。

四、低音弹性与瞬态
动态组默认关闭。弹性静态隆起权重、低音动态起音权重、乐器瞬态权重各为 0.0–200.0%，默认各 100.0%。
可以降低弹性的静态隆起而保留鼓点起音，也可以保留低音分量而弱化起音。低音动态分频 20–1000 Hz，默认 150 Hz。
低音快包络 0.1–50.0 ms，默认 5.0 ms；低音慢包络 5–500 ms，默认 70 ms。
瞬态快包络 0.1–50.0 ms，默认 2.0 ms；瞬态慢包络 5–500 ms，默认 45 ms。
两路各自要求快时间严格小于慢时间，包括分组关闭时的请求；这是两路包络跟踪时间，不把它们误写成标准压缩器攻击／释放。
两路灵敏度各为 25.0–400.0%，默认 100.0%；用于缩放快慢包络差产生的起音程度。
两路最大作用量各为 0.0–12.0 dB，默认 3.0 dB；限制该动态阶段的正负目标增益，并非最终输出峰值保证。负宏值倾向起音柔化，正宏值倾向增强；零宏值仍不产生该路动态效果。
弱信号保护有独立开关，默认关闭，只有专业模式和动态组同时开启才有效。保护电平 −120.0–−30.0 dBFS，默认 −80.0 dBFS；低于它停止动态起音作用，保留静态与直达信号，不作噪声门静音。
关闭动态组恢复原分频、包络、权重、灵敏度和最大作用量。单项复位回对应原算法／中性值，原低音弹性和瞬态宏继续作为基础。

五、干湿、输出和余量
干湿组默认关闭。效果比例 0.0–100.0%，精度 0.1%，默认 100.0%；0% 为本模块输入，100% 为音色处理结果，中间采用线性干湿混合。
滤波改变相位，中间干湿比例不一定等于按同一比例减少所有滤波 dB。静态组合图使用复数滤波响应计算干湿组合，不仅将 dB 数字相加。
输出组默认关闭。模块输出增益 −24.0–0.0 dB，精度 0.1 dB，默认 0.0 dB，作用于混合结果。
额外余量组默认关闭。额外衰减 −24.0–0.0 dB，精度 0.1 dB，默认 0.0 dB，叠加在算法自动预衰减之后，不取消原自动余量逻辑。
原算法根据组合滤波的估计最大增益及两路动态边界自动预衰减；原兼容路径保持原估计方式。专业形状／动态变强时使用相应边界估计，窄 Q 等情况采用更保守的增益上界，避免有限频率扫描漏掉窄峰。状态显示实际自动衰减与手动额外衰减；更保守的余量可能降低电平，不应误认为该滤波或动态参数没有生效。
自动余量用于减少增益叠加引起的超限风险，不是实时音量匹配、LUFS 匹配、真峰值限制器或最终输出不削波承诺；后续音频链仍可能改变电平。

六、独立预设
提供六个系统方向，均需主动应用；保留当前原十项整数和原范围，只重建新增专业请求，不改写原基础，不改变模块电源。
原版兼容：关闭全部专业组、工具，清除专业修正，保留当前原十项和范围。
温暖厚润：叠加温度、低频与厚度方向的修正，温度频率采用 160／3200 Hz、厚度 320 Hz，温度低／高权重 110%／90%，85% 效果。
人声靠前：主要增加人声修正并减少部分厚度，采用约 2000 Hz 人声和 3300 Hz 女毒位置，人声 Q 0.90，85% 效果；不识别人声。
低频弹性：增加深度、弹性与瞬态修正，静态弹性权重 70%、动态起音权重 140%、动态分频 130 Hz、低音快／慢 3／90 ms、低音灵敏度 125%、最大作用量 4 dB；−75 dBFS 弱信号保护、80% 效果及额外 −1 dB 余量。
清亮空气：增加空气感及部分上中频修正，温度高架 4000 Hz、空气感 13000 Hz，对应高架坡度 S 0.800，80% 效果。
柔和耐听：减少两段齿音及瞬态修正，静态弹性／低音动态／瞬态权重 80%／70%／80%，瞬态快／慢 4／65 ms，两路动态上限 2 dB、−80 dBFS 弱信号保护，85% 效果。
以上是确定的处理方向，不表示经过真机主观试听，也不保证任意原基础下都得到同一听感。若原基础已经处在边界，叠加修正可能触及实际宏限制。
所有系统方案的电平与响应图仍默认关闭。原版兼容不是将原十项统一清零；个人预设恢复完整保存基础，系统方向保留应用当时的基础，两者用途不同。
个人收藏支持保存、应用、命名、重命名、当前参数覆盖、删除、导入、单项／全部导出，最多 20 项。
收藏保存原十项、原范围、全部专业请求参数和开关，包括关闭分组中保留的值；不保存模块电源、局部窗口／显示步长、试听、A/B 快照、匹配状态和测量结果。
独立库 tone-favorites-v1.json 不随整体设备配置替换清空，也不覆盖其他音色模块的收藏。应用预设不自动打开电源，不改动其他模块。
文件格式 dsp-audio-tone-presets / version 1，严格 UTF-8，最多 64 KiB、20 项；整份验证后原子写入。
原十项为严格 Int，范围为规范 String；修正为十分之一点整数，频率为 Hz 整数，Q 为百分之一整数，坡度为千分之一整数，快时间为十分之一毫秒整数、慢时间为毫秒整数，dB 为十分之一整数，百分比为十分之一百分比整数。
拒绝未知／缺失／重复字段（包括 JSON 转义后同名）、错误模块／版本／单位、错误类型、非有限／越界值、原值超过原范围、快慢时间关系错误、无效 UTF-8、非法名称／标识及文件内重复名称／标识。
任一条错误或容量不足均整份拒绝，已有库不动；同名导入追加编号并生成新标识，不覆盖旧收藏；写入失败回滚至上次成功内容。
无效原十项或范围不能保存或覆盖收藏，已经打开的输入框和覆盖确认也在提交时重新检查；有效系统方案或已有个人预设仍可用于修复。
含任何新增专业字段的整机配置要求 APK 最低版本 1050；旧配置继续使用原十项和范围。整体配置不保存个人库或临时工具。

七、试听与诊断
试听提供正常处理、原声、效果、效果减原声差分、快照 A、快照 B 和 A/B 测量。比较仅针对本模块，前后其他模块仍按原链路处理。
差分包含滤波相位、静态增益和动态处理变化，不是从歌曲分离出来的独立人声、鼓点或齿音。
A/B 使用同一输入和独立处理状态。未开启匹配的快照 A／B 在预热完成后即可试听，不自动测量；主动选择“测量 A/B 电平”时，才在预热后测量 2 秒 RMS 并作固定衰减匹配。信号不足不建立匹配，仍可关闭匹配继续试听 A／B；不持续追踪，不自动提升音量，不是 LUFS 或真峰值匹配。
修改普通声音参数停止当前试听和匹配，但保留已经保存的 A/B，方便调整后保存另一份；关闭专业模式、折叠、离页、暂停、关闭模块、驱动失效、会话关闭或采样率变化清除全部临时比较。关闭专业模式时也不保留界面中的旧快照标记。
局部窗口、显示步长以及电平／响应图显示开关不改变声音，不应清除已完成的 A/B。
电平工具默认关闭，显示本模块当前音频块输入／输出左右采样峰值和 RMS、超限帧、两路当前动态增益、自动余量、额外余量与实际滤波／分频频率。
这些是模块内部当前音频块的采样电平，2 秒窗口仅用于 A/B 测量；它们不是耳内声压、真峰值、LUFS 或最终音频链输出。
静态响应图默认关闭，分别显示主配置内核的滤波本身及含自动／额外余量、干湿、输出的静态组合响应。实际宏、频率、自动余量和两路动态增益诊断也来自主配置正在处理的内核；新候选预热及交接完成前仍可能显示旧内核的实际值，设置请求保持保存。图中不描绘 A／B 快照、原声、差分等临时路由，也不包含随音乐变化的两路动态作用。
输入电平读取本模块输入，输出电平读取最终实际试听输出，包含当前 A／B、原声、差分或交接路由的实际结果；不能用主配置静态图直接解释任意试听路由的输出电平。
响应图不是完整链路测量、房间测量、耳机测量或当前歌曲频谱；关闭图表不改变声音。
状态与响应图通过同一组合快照读取，防止预设切换过程中混用两个时点的数据。

八、稳定性与兼容
新 80 项参数包原子提交模块电源、原十项、原范围及专业设置，不在后面重复发送旧 11 项覆盖专业结果。
预设或参数改变时准备新状态并平滑交接；预热按实际滤波极点和最长包络确定，上限 30 秒，随后约 20 ms 交接，快速连续更新采用最新有效请求。A/B 快照也独立预热，旧比较路由通过保留状态淡出，不将新快照冒充已经就绪。相同设置重发不无条件清空处理历史。
采样率变化重新设计实际频率、包络系数与诊断，保存请求不被安全限制永久改写；测试需要覆盖低采样率、44.1／48 kHz 及更高采样率往返。
原基础的类型、范围和新参数关系完整检查；无效请求保留上次有效处理，不发送静默默认声音或触发引擎反复恢复。无效基础仍允许关闭模块。
主协议仍为 5、原能力值仍为 2147483647。新增扩展能力查询 GET131234 的第 0 位表示音色专业支持，避免使用有符号整数第 31 位。
SET196640 为 80 项设置，SET196641 为 164 项临时工具，SET196642 为单个 0 清理。
SET196643 为单个 0 的仅关闭电源命令：原基础无效时允许关闭音色模块，保留上次有效基础与专业设置，不用默认基础覆盖来达成关闭。
GET131235 为 64 项状态，GET131236 为 200 项静态响应，GET131237 为 264 项组合快照；严格验证长度、范围、保留字段和同一发布时点。
未声明扩展能力的旧驱动仅接收原 11 项处理，新专业请求保留并提示未生效，不发送未知专业命令或伪造诊断数据。
验证重点为原默认／非零声音兼容、分组关闭恢复、接管置灰、局部窗口不改保存值、工厂方案实际音频、严格导入和写入回滚、快速预设切换、采样率刷新、并发状态一致性及音频回调无分配。
