# USB 采样率跟随与奈奎斯特上限专项检查（2026-10-17）

本轮在 UI49 基础上增加 USB 跟随控制，并收紧参数均衡器的显示与调节范围。没有把播放器设置值或 USB 设备宣告的最高采样率当作驱动当前处理采样率。

## USB 通道能力边界

当前驱动是 AudioFlinger 中的软件插入效果。原生 `INPUT_DIRECT` / `OUTPUT_DIRECT` 是效果输入输出缓冲访问方式，不表示 USB 独占直通；驱动没有硬件隧道或 offload 实现。现有模块安装脚本注册效果库，没有重写 USB HAL 或系统音频策略。

新增开关用于跟随可进入现有效果链的 USB 音频，依据同一效果会话的实际 host rate 和处理帧前进确认活动。在新会话建立或实际采样率变化时后台同步参数；同采样率暂停恢复仅更新状态，保留原有缓存和混响尾声。关闭时停止这项额外跟随，保留原传统模式或增强处理配置。该开关不能强制其他播放器选择高采样率，不能保证截获独占 USB、硬件 offload 或绕过系统效果链的音频；开启状态不等于直通成功。

Android 的 USB mixer attributes 按播放应用配置；`BIT_PERFECT` 明确不应用混音、音量调整或音效。因此不能用该 API 对其他应用的播放伪造全局无损 DSP 直通。依据：[Android Improve audio playback](https://developer.android.com/media/platform/improve-audio-playback)、[Android Audio effects](https://source.android.com/docs/core/audio/audio-effects)。

## 参数均衡器范围

频响图的有效最高频率不超过真实处理采样率的一半；频率控件的有效范围为 1 Hz 至该奈奎斯特上限。48 kHz、384 kHz、768 kHz 分别对应 24000、192000、384000 Hz。图纸缩放与频段调节分开，放大某一局部频段不会裁掉已保存的滤波频率。

用户保存的图纸首选上限保留，低采样率时仅限制当前显示，后续真实采样率上升可以恢复。Q / BW 的固定范围和完整 Double 精度保持，与频率、采样率无关。

显示和保存的中心频率可以精确到 `fs/2`；系数计算对这个唯一端点使用 `fs/2−0.001 Hz` 的左侧值，避免 `tan(π/2)` 奇点及整段被关闭。APK 解析响应与原生 TPT 处理使用相同映射；高于奈奎斯特的旧保存频段仍保留但暂不处理。原生专项 3/3 通过，包含七类滤波器在 48/96/192/384/768 kHz、正负 100 dB 和极限 Q 下的 140 组两秒长流，与原本合法的相邻频率逐样本一致。
