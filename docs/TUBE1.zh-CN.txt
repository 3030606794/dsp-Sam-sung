电子管模拟器 — 第一轮专业增强 ui32 / 1045

一、原版声音与模块独立性
本轮增强 ViPER 的“电子管模拟器”（v_tube），与“模拟谐波染色”（v_analog）及 JamesDSP 的“模拟音色仿真”（dsp_tube）分别保存和处理。
原版代码是左右独立的一阶线性柔化低通：y[n] = 0.5 × x[n] + 0.5 × y[n−1]。它本身不会产生新的谐波。
本轮专业模式新增真正的非线性饱和、音色、干湿混合、输出及饱和过采样分组，不把旧低通换个名称冒充新的电子管算法。
新增处理是可调声音染色，不对应某款真实电子管、放大器电路或物理测量模型。
模块电源与原折叠规则保留。专业总开关及全部新增分组默认关闭。
专业关闭时恢复原版柔化；专业开启、所有声音分组关闭时也保留原版声音。
关闭一个分组只旁路它的处理，保存值保留；重新开启时继续使用保存值。

二、非线性饱和
饱和驱动：0.0–18.0 dB，步长 0.1 dB；增加送入饱和曲线的驱动，0.0 dB 表示没有额外驱动，不表示已开启的饱和曲线被旁路。
饱和软硬度：0.0–100.0%，步长 0.1%，默认 50.0%；0% 为硬曲线，100% 为 tanh 软饱和，中间连续混合，改变曲线的压缩与转折形状。
饱和非对称度：−100.0–100.0%，步长 0.1%，默认 0.0%；改变正负半周的对称关系以及偶次谐波的倾向。
非对称度不是偶次谐波百分比，也不直接指定二次、三次谐波的精确幅度。
关闭饱和时三个数值置灰并保留，重新开启恢复操作。
音乐信号的实际谐波和增益变化取决于输入电平、频率及所有处理参数；面板上的音乐峰值／RMS 不能当作 THD 测量。

三、音色与原版柔化
原版柔化比例：0.0–100.0%，步长 0.1%，默认 100.0%；控制原版柔化与直接信号的组合，0% 旁路柔化，100% 使用完整柔化。
柔化低通频率：0 或 20–20000 Hz，步长 1 Hz；0 使用原版系数，不表示柔化旁路。
饱和前低切：0 或 20–1000 Hz，步长 1 Hz；0 表示低切旁路。它只过滤送入非线性的分量，未参与非线性的基础低频仍保留，不是对整个输出切除低频。
处理后高切：0 或 1000–20000 Hz，步长 1 Hz；0 表示高切旁路。
低采样率下，驱动会将实际截止频率限制在可用频率范围内，状态区显示实际值。
处理顺序为基础柔化／柔化混合 → 饱和支路低切及非线性残差 → 残差直流处理后加回对齐的基础信号 → 总处理声高切 → 干湿混合 → 输出增益。
音色组关闭后恢复原版柔化，三个滤波设置与柔化比例均保留。

四、干湿混合、输出与过采样
干湿混合：0.0–100.0%，步长 0.1%，默认 100.0%；0% 为本模块原声，100% 为处理后声音，采用线性混合。
原声与处理路径按实际处理延迟对齐；本模块输出增益仍作用于最后混合结果。
输出增益：−24.0–0.0 dB，步长 0.1 dB，默认 0.0 dB；不自动提升输出。
饱和过采样支持 2×／4×，开关默认关闭，保存倍率默认 2×。
过采样仅用于已开启的饱和支路；饱和关闭时，过采样开关和倍率置灰并保留保存值。
过采样降低非线性产生的混叠，不能保证完全消除，也不增加音源原有信息量；它增加处理量和少量延迟。
2×／4× 饱和路径使用 31 个原处理采样的对齐延迟，原声、基础信号与 A/B 对比会补齐到相同延迟。实际倍率、处理采样率及延迟由驱动报告；不要将保存的倍率当作当前已经生效的倍率。

五、数值与独立个人预设
数值支持滑杆、直接输入、加一／减一和单项复位；复位只恢复该项默认值，不改变其他数值和开关。
已经打开的输入框也受当前开关约束，被接管或置灰后不能通过旧弹窗提交。
系统声音方案包括原版默认、轻暖人声、厚实和通透，只有主动应用时载入；不会更改首次安装或未操作时的默认声音。
“原版默认参数”恢复专业关闭、所有分组关闭及全部默认数值，保留模块电源。
“轻暖人声”采用 6.0 dB 驱动、30.0% 干湿和 2× 过采样；“厚实”采用 12.0 dB 驱动、60.0% 干湿和 4× 过采样；“通透”降低原版柔化比例，采用 4.5 dB 驱动、25.0% 干湿和 2× 过采样。
这些名称描述参数取向，不对应真实管型号，不表示经过真机耳机试听，也不自动匹配方案音量。
最多保存 20 个个人预设，支持应用、重命名、用当前参数覆盖、删除、导入和导出。
个人预设保存完整专业参数及各组开关，包括暂时关闭组的保存值；不保存 v_tube 电源、临时试听、A/B 快照、匹配状态及测量结果。
个人库为 tube-favorites-v1.json，与其他效果个人库独立，不随整体设备配置替换而清空。
导出格式为 dsp-audio-viper-tube-presets / version1，整数单位为 tenth-dB、tenth-percent、Hz、integer-factor。
导入先验证完整文件，再原子写入；任一条目错误、超过库容量或文件超过 64 KiB，整份拒绝并保留原库。
未知或缺失字段、重复 JSON 字段、错误模块／版本／单位、错误数值类型、非整数、非有限值、越界值、无效滤波间隔值、非 2／4 倍率、无效 UTF-8、无效名称或标识均拒绝。
同名导入自动添加编号，导入项分配新标识，不覆盖已有收藏；写入失败回滚到上次成功数据。
包含新增电子管专业字段的整体设备配置要求 APK 最低版本 1045。

六、试听与电平
支持正常处理、原声、处理后效果、效果差分、快照 A、快照 B 和 A/B 电平测量。
差分表示完整处理支路与延迟对齐原声之差，包含柔化、滤波及非线性变化，不等于纯谐波。
A/B 为两套独立参数和处理状态，使用同一输入；预热滤波与延迟后测量 2 秒 RMS，再采用固定衰减匹配。
匹配不持续追踪、不提升电平，信号不足时不建立匹配；设置变化后需要重新测量。
实时电平开关默认关闭，显示本模块输入和输出左右声道的采样峰值、RMS 及输出超过 0 dBFS 的帧数。
仅切换实时电平显示不改变声音、临时试听或已有 A/B 匹配，也不重建正在编辑的数值行。
这些读数不是 LUFS、真峰值、耳内声压或 THD；后续已开启效果仍可改变最终输出。
收起、离开页面或暂停页面清除临时快照；关闭模块、专业模式、改变声音设置、驱动失效或会话停止时结束临时试听。
编辑、保存或应用个人预设不会自动开启模块电源。

七、接口与验证
新增能力位 33554432；专业 SET65649 为 20 项，工具 SET65650 为 44 项，清理 SET65651 为单个 0，运行 GET131225 为 32 项。
旧驱动不支持新能力时保留参数编辑，提示专业处理未生效，继续使用原版电子管柔化。
验证范围包括原声音一致性、饱和曲线与谐波倾向、过采样混叠变化及延迟、极值与非有限输入、快速分组／倍率切换、采样率变化、A/B 及失败恢复。
实际测试通过数量、原签名、源码版本、驱动 ABI、文件完整性及构建结果以本轮交付核验记录为准。
本地验证不代替 USB 真机路由与长时间播放试听；未增加录音或网络权限。
