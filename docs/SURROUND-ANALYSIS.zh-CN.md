# 环绕功能分析与实现边界

本轮仅新增环绕；用户在确认系统级变速限制后取消了速度与音高需求。

## 输入证据

用户从自己手机提供 `Neutron Player_2.29.0.apk`。SHA256：`be8013cd74962e9cb93e338a02191aff6a0eaf3fb9694b0b6cc4f0e2a40a8343`。
仅静态读取语言资源、ELF常量及界面相关反汇编；未运行修改版、未改变授权逻辑，原APK、商业库和反汇编片段不进入本仓库。

语言资源将环绕对应到 `DSP_RACE`，指向外部扬声器的 Ambiophonics。官方资料亦确认此功能基于 R.A.C.E.：[中子说明](https://neutroncode.com/feature_surround)。独立算法依据 [Glasgal 与 Miller 的公开论文](https://www.filmaker.com/papers/RGRM-RACE_rev.pdf)。

## 从安装包确认的界面语义

- 当前参数刷新/限制函数位于 ARM64 `libneutronmp.so` 的 `0x204550`。
- 低频边界 `FREQ_LO` 为10–800Hz，高频边界 `FREQ_HI` 为4000–16000Hz，衰减为0.5–10dB，延迟为20–210μs。
- 预设记录每组20字节，8组160字节。按钮选择索引0–7，仅当前槽参与处理。
- `0x303330` 的重置分支给出下列预设；截图第一组300/9000/10/20已被修改，不代表原厂值。
- 绘图调用只传入低、高频边界，不传入衰减和延迟。因此曲线只表示处理频段，不代表实际房间或完整RACE响应；UI修订版按用户要求移除了图上说明文字。

## 独立实现

本项目选择二阶Butterworth高通与低通界定处理频段，加上反相跨声道反馈、衰减及分数采样延迟。未证明中子商业DSP内部的滤波阶数、归一化和插值算法，不宣称输出逐样本相等。

原生实现细节与测试见 `native/surround` 及 `native/tests/SurroundTests.cpp`。环绕位于PEQ之后、JamesDSP之前，让已有James输出限幅处理环绕可能增加的峰值。后续声场处理与环绕会叠加，试听时可分别比较。

新参数ID为196609，六个int32：schema=1、enable、lowHz、highHz、attenuationMilliDb、delayUs。原协议5保留，增加能力位16，总能力31。App先检查能力；旧驱动不接收这个参数，已存启用状态也不会显示为成功生效。

八槽及选中索引进入正常预设/设备配置。编辑不改变开关；默认关闭。预设导出包含新参数时最低应用版本1013；加载旧预设时清除环绕旧状态。

## 验收

云端验证原生信号行为、参数协议、APK和两种ARM架构驱动；通过编译和自动测试不等于手机HAL路由、扬声器摆位或听感验收。由用户安装配套模块并重启后验证。未自动安装、刷模块、修改用户预设或重启设备。

## 环绕界面与独立预设库（surround1-ui1）

应用版本1014，沿用surround1驱动及参数协议，无需更新驱动。本轮按用户要求本地编译。

- 移除处理频段/参考采样率标题及用途说明。升级到此布局后曲线默认固定，后续记住用户固定/取消选择。
- 底栏固定为“重置、电源、预设”，三个等宽区域；电源无背景，开启绿色、关闭灰色。
- 四项参数的数值框放在滑杆右侧，单击输入；双击数值框或滑杆，只恢复当前编号下该项出厂默认值。
- “重置”恢复当前1–8编号的四项默认值，保留其他编号与环绕开关。
- 自定义环绕预设独立保存最多20个，支持命名、改名、覆盖、删除、单个/全部导出与批量导入。应用只替换当前编号四项参数，不改变选中编号或开关。
- 独立库不随设备配置覆盖；JSON包含格式标记、版本和明确单位，拒绝错误范围、未知字段、错误编码或超出20个的导入。单文件上限256KiB，任何条目不合法时整批不写入；重名导入自动加后缀。
- 数值编辑保留毫分贝精度；滑杆刻度仍是0.05dB。曲线计算、驱动处理和其他音效保持原实现。

后续建议（本轮未实现）：优先考虑可选步长与长按加减、临时A/B对比；0.1μs延迟和独立干湿混合比例需要扩展驱动及验证，不能只增加界面控件。

本地验收：release构建和68项回归通过，包括参数界面/手势、预设库与管理弹窗、文件选择取消与旋转，以及受共享双击工具影响的输出、MSEB、PEQ控件。Windows测试只对AtomicFile私有rename操作模拟Android/POSIX覆盖语义，生产原子写入代码与失败回滚断言不替换。未执行真机安装或试听。
