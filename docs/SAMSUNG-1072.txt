三星 1072 更新交付注意

适用设备：SM-S9180，Android 15。
已确认实际音效接口为 HIDL 7.0，使用配套 legacy DSP 驱动，不能仅按 Android 版本改成 AIDL。
当前设备为 APK 1062 / 驱动 1061；本次更新为 APK 1072 / 驱动 1072，版本 0.1.0-alpha15-samsung-ui54.4。

升级时先覆盖安装 APK，保留 Root 授权，再通过现有 Root 管理器安装配套 legacy 驱动 ZIP，最后由用户手动重启。不要卸载应用或清除数据，以保留预设、音效参数和应用名单。APK 与旧 1061 驱动不可作为本次完整交付组合。

本版合入最新通用功能：专业页与主页参数同步、频响图及滑杆刷新优化、当前专业模块约 0.5 秒状态采集、外观和总开关动效、Root 授权恢复、全局/播放器会话切换、应用指定与排除、系统应用批量排除，以及应用搜索列表并发更新修正。
指定与排除名单互斥；批量排除系统应用会跳过已指定应用及 DSP 自身，按 UID 去重。开启“仅处理指定应用”但名单为空时暂停处理，通过主页提示或名单页 ＋ 添加应用。

首次启动新版采用三星独立标记 samsung_global_mode_default_v1，一次性恢复全局模式并关闭高清会话模式；以后保留用户的手动选择，不反复重置。
保留原包名 com.dspfusion.android、正式签名、模块 ID dsp_fusion 和协议 5。此版不包含联想杜比开关、启动脚本或 Y700 元模块依赖。

高清会话模式只跟随系统提供的可处理音轨及驱动实际采样率，不强制硬件高清输出，也不能拦截播放器独占 USB。主页显示实际处理状态；均衡器频率上限随实际采样率的一半变化。

本次不自动运行回归、单元测试或 Lint，不自动安装、刷模块或重启。交互、切歌及音效听感由用户在三星真机验收，不宣称全部异常已消除。
