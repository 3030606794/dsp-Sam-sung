模拟音色仿真 — 专业增强与染色试听完善 ui35 / 1048

一、范围、原版声音与独立性
本轮增强 JamesDSP 的“模拟音色仿真”（dsp_tube），与 ViPER 的“电子管模拟器”（v_tube）、“模拟谐波染色”（v_analog）及其他效果分别保存和处理。
原算法将声音分成六路，对中间四个频段分别加入平方染色，再重新组合。第一至第四路表示四个频段，不是二次、三次、四次和五次谐波阶次。
某一路染色强度为 0 时，只移除该路附加染色，仍保留对应频段的基础声。
本模块原来没有三档或房型。新增系统方案为可主动应用的完整参数方案，不改变首次安装的默认声音。
原开关与折叠规则保留；专业总开关、核心分段染色、分频与音色、直流消除、干湿、输出、驱动补偿、FIR 抗混叠及实时电平均默认关闭。
关闭专业模式恢复原版处理。专业开启但声音分组关闭或全部有效参数中性时保留原版路径，临时试听另行标示。
关闭分组后，相关参数置灰并保留保存值，重新开启恢复；专业总开关关闭也不会删除已经保存的专业参数。
本模块和其他效果同时开启时，仍按现有音频链顺序叠加；独立保存不表示同时开启时听感互不影响。

二、旧前级参数与真实驱动
旧版本同步流程先设置 tube_drive，再启用模块；启用初始化将前后级增益重置为 1。因此旧界面保存的前置放大器数值并不等于原路径实际驱动，历史实际驱动为 0.0 dB。
为保留原声音，本轮普通兼容模式继续采用实际 0.0 dB 的旧处理，保留旧 Float 类型 tube_drive 保存值供识别，不把它迁移成新的有效驱动。
旧前级滑杆已按用户要求隐藏，后台旧 Float 保存值保留，不让一个不实际生效的只读杆占据界面。需要改变染色驱动时，开启专业模式和核心组，使用“染色驱动”（原“真实前级驱动”）。
专业真实前级驱动为 −3.0–12.0 dB，步长 0.1 dB，默认 0.0 dB。它在新的专业处理路径真实生效，不会被重复 Enable 覆盖。
总染色强度扩展为 0.0–1000.0%，默认仍为 100.0%；四路独立染色强度仍各为 0.0–200.0%，默认 100.0%；步长均为 0.1%。
总量与各路倍率相乘。100% 表示该路径的基础注入量，0% 移除相应附加染色；这些数值不是音乐谐波占比或 THD。
本轮只扩大可主动选择的专业总量上限，不提高默认强度，不把专业总开关或各分组默认打开；原有 0–200% 参数声音保持。
四路滑杆调的是新增平方染色，不能作为四段原声 EQ 使用。分频点控制染色分配和重组相位，保持主体幅度；染色低切／高切也只滤新增支路。
默认完整驱动补偿将基础声音的驱动增益还原；真实前级增加主要改变染色，整体音量未明显变大不表示参数没有生效。
染色强度与输入电平有关。对 ui34 冻结算法的 48 kHz／1 kHz 单音测量，输入峰值 −18 dBFS 时默认 H2 约为 −47 dBc，真实驱动 +12 dB 后约为 −35 dBc，而总 RMS 只变化约 0.0033 dB；输入更低时相对染色更弱。这是该单音条件的量测，不代表任意音乐的 THD 或真机听感。
核心组关闭时，专业驱动和四路倍率不接管处理；保存的数值保留。

三、分频与音色
五个分频点均可在 50–20000 Hz 内请求，必须严格升序且相邻至少相差 50 Hz；默认依次为 600、1900、4400、8000、12000 Hz。
中间四个区间对应四路染色；低于第一点与高于第五点的外侧频段继续保留基础声。
原分频器按基础采样率设计，却在自动过采样速率下运行；原标称点为 300、950、2200、4000、6000 Hz，常见 2× 时等效物理点为 600、1900、4400、8000、12000 Hz。
专业路径按实际过采样采样率设计分频器，避免倍率改变后物理分频点随倍率翻倍。音色组默认采用常见旧路径的等效频点，关闭音色组则采用当前原版自动倍率对应的等效点。
分频点和染色支路滤波必须处于可用频带。专业路径遇到较窄频带时，将五点按同一比例缩放，使最高点不超过内部处理采样率的 45%，保留顺序和比例；实际频率显示在状态区。
染色支路低切：0 表示旁路，否则为 20–1000 Hz，默认 0。
染色支路高切：0 表示旁路，否则为 1000–20000 Hz，默认 0；两个滤波均开启时，低切必须小于高切。
独立直流消除开关默认关闭，仅音色组开启时可调；截止频率为 1.0–30.0 Hz，步长 0.1 Hz，默认 5.0 Hz。
平方染色可能产生直流分量。直流消除、低切和高切均只处理附加染色支路，不滤除基础声对应的低频或高频。
保存值表示请求参数，安全限频不会永久改写保存值；采样率恢复后重新计算实际参数。

四、干湿、输出与驱动补偿
干湿混合为 0.0–100.0%，步长 0.1%，默认 100.0%。混合的是相位一致的六路重组基础声与附加染色。
0% 为去除附加染色后的重组基础声，仍包含分频重组、当前驱动补偿及输出处理；它不是完全未经处理的原始输入。需要听完全原始输入时使用独立“原声”试听。
100% 为完整染色处理声；混合采用线性比例，不自动调整响度。
模块输出增益为 −24.0–0.0 dB，步长 0.1 dB，默认 0.0 dB，作用于混合后的最终模块输出，不自动提升电平。
驱动增益补偿为独立开关，默认关闭；关闭时沿用原有完整反向补偿 1/g。开启后可调 0.0–100.0%，步长 0.1%，默认 100.0%。
其中 g 为真实前级线性增益，补偿系数为 g^(-比例)。0% 不补偿，100% 完整反向补偿；补偿是确定的增益关系，不代表自动等响度或防削波。
调低补偿可能提高基础声和染色后的电平，可配合输出衰减与电平工具判断。

五、原版自动品质与 FIR 抗混叠
原算法已有随内部处理采样率选择倍率的 IIR 自动过采样，常见 44.1／48 kHz 内部处理使用 2×。关闭新抗混叠组表示使用原版自动品质，不表示算法完全没有过采样。
新的品质组提供真正 FIR 升采样及降采样的 2×／4×，开关默认关闭，保存倍率默认 2×。
新 FIR 2×／4× 均增加 31 个内部基础处理采样的固定延迟；原版自动 IIR 的相位与频率有关，不把它标成固定 31 个采样。
专业重组基础声与四路染色使用匹配的降采样滤波，干湿两端相位一致；原声、差分及 A/B 按实际固定延迟对齐。
原声试听保留原始输入的相位，不能用一个固定时间延迟消除分频器本身的相位变化。效果差分因此包括分频相位、滤波和增益变化，不等于纯谐波。
状态区分别显示外部音频采样率、JamesDSP 内部处理采样率、实际倍率和新增固定延迟；外部 USB 192 kHz 不代表此算法直接按 192 kHz 内部处理。
过采样用于降低非线性产生的混叠，不能保证全部消除，也不能增加音源原有细节；4× 会增加处理开销。
启用、参数更新和采样率刷新分开处理。重复同步不无条件清空滤波历史，声音切换采用准备、预热和过渡；准备失败时保留可用处理状态。

七、试听与电平诊断
支持正常处理、原声、效果、效果差分、快照 A、快照 B、A/B 电平测量、第一至第四路染色独听，以及本轮新增的混合前总染色独听。
各路独听输出的是该频段新增的染色残差，不是完整分频原声，也不是对应阶次的单独谐波。
总染色独听合计四路染色增量，不包括基础原声；四路和总染色独听均取干湿混合前的染色，但仍包含模块输出增益及染色滤波。干湿比例为 0% 时可独听已经产生却未混入正常输出的染色。
新增临时独听增益可选 0／6／12／18 dB，仅在四路或总染色独听时放大试听支路。默认 0 dB，不改变正常声音、原声／效果／差分、A/B 测量或预设参数；停止、收起、离页、暂停、关闭模块或驱动失效后清理。
A/B 使用同一输入和两套独立处理状态；预热后测量 2 秒 RMS，再作固定衰减匹配，不持续追踪，不提升电平。
信号不足时不能建立匹配；影响声音的设置改变后，需要重新保存／测量。只切换实时电平显示不改变声音，也不清除已有 A/B 匹配。
实时电平默认关闭，显示本模块输入／输出左右声道采样峰值、RMS、超限帧计数、输出直流均值及混合前四路附加染色 RMS。
直流均值是输出样本的慢速统计，不能凭音乐的短时读数宣称直流完全为零；四路 RMS 反映该模块残差，不是音乐 THD。
这些读数不是 LUFS、真峰值、耳内声压或实际音乐谐波占比；后续模块仍可能改变最终输出。
收起、离开或暂停页面会清理临时工具；关闭模块／专业模式、改变声音设置、驱动失效或会话停止时结束临时试听，避免旧试听状态继续影响声音。
应用或保存预设不自动开启模块电源。文件导入／导出、重命名和删除本身不改变当前声音参数。

八、接口与验证边界
原专业能力位 134217728；本轮总染色上限与独听扩展能力位 536870912。
