动态音色处理 — 第一轮专业增强 ui35 / 1048

一、范围、原版声音与独立性
本轮增强 ViPER 的“动态音色处理”（v_dynamic），与 JamesDSP“动态范围压扩器”、低频增强、电子管模拟器、模拟谐波染色、模拟音色仿真及其他效果分别保存和处理。
原算法主要按固定滤波分带重新组合音色，没有电平阈值、攻击、释放或包络检测。名称中的“动态”不表示旧实现已经有本轮新增的自适应检测。
保留六个原基础预设：均衡、温和、厚实、清晰、深低音、开放声场；保留原强度 0–100、原默认值、原开关和折叠规则。
“深低音”采用固定 55 Hz 共通低频注入支路；另五个预设采用分带重组。两条算法原本不同，不把无效参数做成可调滑杆。
专业总开关、核心精调、频段与音色、电平自适应、干湿混合、输出增益、实时电平与响应图均默认关闭。
关闭专业模式恢复原版声音。专业开启但新增声音分组关闭或有效参数为中性值时仍保留对应基础声音。
六个基础预设始终可选，精调叠加在当前预设与原强度之上。普通模式与深低音模式的选择由基础预设决定，拖动专业频率不会暗中切换算法。
本模块和其他模块同时开启时，仍按已有音频链顺序叠加；独立保存不表示多个模块同时开启时听感互不影响。
本轮同时隐藏上一版本“模拟音色仿真”的旧只读前级滑杆，后台旧保存值保留；专业核心中的“染色驱动”仍可正常调节。

二、核心音色精调
核心组默认关闭，只在专业总开关和核心组开启时接管原强度。被接管的原强度滑杆置灰并说明原因；关闭核心组或专业模式后恢复原强度调节。
核心精调仍以保存的原强度作为基础。基础预设始终能切换，不因核心组开启而置灰。
分带模式开放三项：
1. 低频整体增益修正：−12.0–12.0 dB，步长 0.1 dB，默认 0.0 dB；在基础低频线性增益之上乘以修正倍率。
2. Y 低段比例修正：−100.0–100.0 个百分点，步长 0.1，默认 0.0；加到当前基础预设的对应低段比例上。
3. Y 高段比例修正：−100.0–100.0 个百分点，步长 0.1，默认 0.0；加到当前基础预设的对应高段比例上。
Y 低段与 Y 高段是两个频段，不是左声道和右声道；它们的比例不代表音乐频段占比，也不是标准 EQ 的 dB 增益。
深低音模式开放两项：
4. 深低音注入量修正：−100.0–100.0 个百分点，步长 0.1，默认 0.0；100% 基础注入量加上此修正。−100 个百分点移除注入，基础输入仍保留。
5. 深低音共振 Q 修正：−2.40–2.40，步长 0.01，默认 0.00；叠加到原强度对应的基础 Q，实际 Q 限制为 0.10–4.00。
原强度 s 的基础低频增益为 1 + 0.2s；深低音基础 Q 为 0.5 + 1600 × (s/100) / 666。
两个 Y 比例及深低音注入比例最低为 0，不允许负比例反相；超出有效范围的请求修正仍保留，状态区显示实际值。
分带模式的深低音专用参数、深低音模式的分带参数均置灰，保存值保留。切回对应模式时恢复可调与已保存的修正。
单项复位将修正归零，恢复当前预设及当前原强度对应的基础参数，不把强度恢复到首次安装默认值。

三、频段与音色
音色组默认关闭。分带模式开放三个有效分界修正：
1. X 下分界修正：−1900–1900 Hz，步长 1 Hz，默认 0。
2. Y 下分界修正：−500–500 Hz，步长 1 Hz，默认 0。
3. Y 上分界修正：−1000–1000 Hz，步长 1 Hz，默认 0。
分界在当前基础频率上加修正，复位回当前基础值。旧算法的 X 上分界会在重组相加中抵消，本轮不增加无实际作用的 X 上分界滑杆。
这些分界来自原分带滤波结构，不能直接等同于标准 −3 dB 截止频率，实际作用可通过响应预测和增强支路独听判断。
深低音模式开放深低音频率修正：−35–145 Hz，默认 0，基于原 55 Hz，常规请求范围 20–200 Hz。此项不会把深低音切成普通分带算法。
两种模式共用增强支路低切与高切：
4. 低切保存值为 0 或 10–300 Hz，默认 0 表示旁路。
5. 高切保存值为 0 或 100–20000 Hz，默认 0 表示旁路。
低切与高切都开启时，低切必须小于高切；两者只滤波低频处理支路，不对未增强的主干声音作全频滤波。
实际频率限制为 10 Hz 至当前处理采样率的 45%，Y 上下分界至少相差 1 Hz；保存请求值与实际生效值分别显示，安全限制不永久改写请求值，采样率恢复后重新计算。
手动编辑 Y 分界时拒绝当前上下交叉。更换基础预设可以保留原有修正，派生边界不合适时由驱动安全限制实际频率，不整份丢弃保存参数。
其中 X 下分界、Y 下分界、Y 上分界、深低音频率、支路低切与高切合计六项；界面只开放当前算法有效的参数。

四、真正的电平自适应
自适应是本轮新增的实际检测与包络算法，默认关闭，与动态范围压扩器独立，不改写压扩器的设置。
从输入的检测频段提取左右联动峰值或 RMS 电平；左右共用回收量，减少左右各自调节造成的声像摆动。
检测频段依次经过低切和高切。峰值取左右绝对值较大者，RMS 对左右平方平均作固定 20 ms 一阶积分后开方。
检测电平较高时降低本模块低频处理支路的幅度，电平降低后恢复原设定的处理量。它不根据系统音量或耳机灵敏度判断耳内响度，不在弱信号时自动提高超过设定的增强量。
可选峰值／RMS 检测，默认 RMS；不是 LUFS 检测或人声识别。
七项数值如下：
1. 检测频段下限：20–500 Hz，默认 20 Hz。
2. 检测频段上限：60–2000 Hz，默认 250 Hz；必须高于检测下限。
3. 回收阈值：−60.0–−6.0 dBFS，步长 0.1 dB，默认 −18.0 dBFS。
4. 软拐点宽度：0.0–12.0 dB，步长 0.1 dB，默认 6.0 dB；0 为硬拐点。
5. 最大增强回收量：0.0–18.0 dB，步长 0.1 dB，默认 6.0 dB。
6. 攻击时间：1.0–200.0 ms，步长 0.1 ms，默认 10.0 ms。
7. 释放时间：50–2000 ms，步长 1 ms，默认 250 ms。
硬拐点时，目标回收量等于检测电平超过阈值的 dB 数，限制在 0 与最大回收量之间；不是另有隐藏压缩比。
软拐点以阈值为中心：令 o 为检测电平减阈值、k 为拐点宽度，o≤−k/2 时为 0，o≥k/2 时为 o，中间为 (o+k/2)²/(2k)，再受最大回收量限制。
回收 dB 使用攻击／释放一阶平滑：每经过一个设定时间约完成目标变化的 63.2%，上升用攻击、下降用释放；最终处理支路乘以 10^(−回收dB/20)。
实际回收量显示的是本模块处理支路的衰减，不是整首音乐的动态范围压缩量。原强度为 0 或支路贡献很小时，有回收读数也不保证主观差异明显。
普通分带模式的低频支路与主干存在滤波相位关系；减少支路并不保证完整输出每个低频点都单调变小，某些频点可能因相消减少而略有增加。它不是全低频压缩器或限幅保证，响应图按当前回收量预测实际合成结果。
主干声音不作本模块的宽带压缩，后续模块的压扩、限幅和输出仍可能改变最后电平。

五、干湿与输出
效果比例 0.0–100.0%，步长 0.1%，默认 100.0%；组关闭时保持完整原处理声。
0% 使用固定延迟对齐后的输入，100% 使用完整处理声，中间线性混合。普通分带模式对齐 3 个采样，深低音模式为 0 个采样。
固定延迟对齐不能消除原分带滤波器随频率变化的相位。中间比例可能受到分频相位影响，不将它宣称为完全相位匹配的干湿路径。
原声试听另提供输入基准。效果差分包括滤波相位、频段重组和增益变化，不等于纯粹新增低音或谐波。
模块输出增益 −24.0–0.0 dB，步长 0.1 dB，默认 0.0 dB；作用于混合后的模块输出，不自动提升电平或承诺防削波。
输出组默认关闭；需要留出余量时可主动开启衰减，并结合输入／输出峰值与 RMS 判断。

六、数值交互与独立预设
共 20 个数值：核心 5 项、音色 6 项、自适应 7 项、效果比例和输出增益各 1 项。
有效数值支持滑杆、直接输入、加一／减一及单项复位。分组关闭或算法不适用时置灰，已打开的输入框也不能绕过当前禁用状态写入。
关闭分组保留保存值，重新开启恢复；复位只恢复本项基础值或中性默认值，不改变模块电源、当前基础预设、原强度或其他分组。
拒绝错误类型、越界、额外小数、非有限数值、低高切空隙／交叉和检测频段交叉，不悄悄截断成另一个输入值。
主界面保留原六个基础预设。新增四项可主动应用的系统方案：
原版兼容：均衡基础、强度 0、专业和全部新增组关闭，恢复首次安装的对应原版参数。
柔和低频：均衡基础、强度 12、低频整体 −1.0 dB、Y 低段 +10.0／高段 −2.0 个百分点、X 下分界 +40 Hz、Y 上分界 +20 Hz、支路 20–500 Hz；RMS 检测、−24.0 dBFS 阈值、6.0 dB 拐点、6.0 dB 最大回收、10.0／300 ms 攻击释放；70% 效果比例、−2.0 dB 输出。
紧致鼓点：深低音基础、强度 18、注入量 −10.0 个百分点、Q 修正 −0.10、深低音频率 +15 Hz、支路 25–200 Hz；峰值检测、−18.0 dBFS 阈值、3.0 dB 拐点、8.0 dB 最大回收、3.0／180 ms 攻击释放；65% 效果比例、−3.0 dB 输出。
低电平恢复：厚实基础、强度 15、Y 低段 +15.0 个百分点、Y 上分界 +15 Hz、支路 20–650 Hz；RMS 检测、−30.0 dBFS 阈值、8.0 dB 拐点、9.0 dB 最大回收、15.0／500 ms 攻击释放；80% 效果比例、−3.0 dB 输出。
后三项同时启用核心、音色、自适应、干湿与输出组；实时电平和响应图关闭，只有主动应用才启用这些专业设置。
“低电平恢复”指强信号退去后恢复方案设定的低频处理，不表示自动增大弱信号音量。方案名称只描述调节方向，不表示模拟特定器材、经过真机试听或自动等响度。
个人预设最多 20 项，支持保存、应用、重命名、当前参数覆盖、删除、单项／全部导出和导入。
个人预设保存基础预设 String v_dynamic_preset、原强度 Int v_dynamic_strength，以及全部 dynamic_pro_* 设置和开关，包括关闭分组的保存值。
不保存模块电源 v_dynamic、临时试听、A/B 快照、匹配状态或测量结果；应用预设不自动打开模块电源。
个人库 dynamic-favorites-v1.json，与其他模块收藏库分别管理，不随整体设备配置替换而清空。
导出格式 dsp-audio-dynamic-tone-presets / version1，单位标记 tenth-dB,tenth-percent,Hz,hundredth-Q,tenth-ms,ms。
Q 修正保存为百分之一 Q，攻击保存为十分之一 ms，释放保存为整数 ms；各字段类型和单位以固定 schema 为准。
文件最多 64 KiB、最多 20 条，按严格 UTF-8 读取。先验证整份文件再原子写入，任一错误或容量不足时整份拒绝并保留原库。
拒绝未知／缺失字段、重复 JSON 字段（包括转义同名）、错误模块／版本／单位、错误类型、非整数数值、非有限值、越界值、错误频带关系、非法 UTF-8、无效名称／标识和文件内重复名称／标识。
基础预设只接受规范字符串 "0"–"5"，不接受整数、前导零、空格或小数；原强度仅接受 0–100 整数。
导入与已有收藏同名时追加编号，新条目分配新标识，不覆盖已有收藏；写入失败回滚到上次成功的内容。
包含新增动态音色专业字段的整体设备配置要求 APK 最低版本 1048；旧配置仍可恢复原基础预设及原强度。

七、试听与诊断
提供正常处理、原声、效果、效果差分、快照 A、快照 B、A/B 电平测量、低频处理支路独听和检测信号独听。
低频处理支路独听是本算法的低频重组／注入贡献，不是原曲低频的精确分离，也不是单独谐波。检测独听是自适应检测滤波后的输入，不等于最终增强支路。
A/B 用同一输入与独立处理状态，完成预热后测量 2 秒 RMS，再作固定衰减匹配；不持续追踪、不提升电平，也不是 LUFS 匹配。
信号不足时不建立匹配；修改影响声音的参数后需重新保存快照及测量。仅切换实时电平或响应图不改变声音，不清除已完成的匹配。
实时电平默认关闭，显示本模块输入／输出左右采样峰值和 RMS、超限帧、检测电平与实际动态回收量。它们不是耳内声压、真峰值或 LUFS，后续处理可能改变最终输出。
响应图默认关闭；使用驱动当前实际滤波系数和当前回收量冻结计算的幅度／相位预测，显示处理声、对齐干声和低频处理支路。
图中使用左右相同输入的参考条件；深低音支路由左右求和注入，不能把图中的单声道参考响应理解为任意立体声素材的固定响应。
启用自适应后算法随时间变化，曲线只是当前包络状态下的预测，不是把动态系统当成固定 EQ，也不是真实房间或耳机声学测量。
收起、离页、暂停、关闭模块／专业模式、改变声音参数、驱动失效或会话停止时清理临时试听；预设导入导出、重命名和删除本身不改变声音。

八、稳定性、接口与验证边界
专业设置作为完整参数包提交，避免预设频率、增益、强度分别到达时形成中间组合；切换处理状态先准备和预热，再渐变过渡。
连续快速更新使用最新目标，准备失败保留仍可用的处理状态；重复相同参数不无条件重置检测与滤波历史。
现有远端同步会缓存相同的旧参数包，并非每次无关界面编辑都会重发相同原预设；本轮也不依赖频繁清空状态来处理采样率变化。
采样率变化重新计算系数与安全频率，不改写保存请求值；重点验证六个预设往返、普通／深低音转换、连续拖动、边界输入、暂停恢复、不同采样率与准备失败。
新增能力位 268435456；SET65655 为 36 项完整设置，SET65656 为 76 项工具包，SET65657 为单个 0 清理；GET131228 为 48 项运行状态，GET131229 为 200 项响应预测。
应用通过 GET131230 一次读取 248 项组合快照（48 项状态＋200 项响应），确保两份数据对应同一发布时点，避免换预设或音频处理期间混列新旧响应。
旧驱动未声明新能力时保留编辑参数并提示专业处理未生效，兼容原预设与强度路径，不伪造专业运行状态。
应用测试、原生音频测试、图像验收、原签名、源码版本、驱动 ABI、校验值与正式构建结果，以本轮交付验证记录为准。
本地验证不代替 USB 真机路由、长时间播放或主观试听；本轮不操作手机，不增加录音或网络权限。
