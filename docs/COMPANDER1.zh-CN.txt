一、范围与原版声音
本轮增强 JamesDSP“动态范围压扩器”，与 ViPER“动态音色处理”分别保存和处理；不合并两个模块，也不改写其他模块的参数。
保留原七点动态曲线、五档粒度、四种算法模式，以及原模块开关、折叠规则和默认声音。
原四模式为均匀短时傅里叶、多分辨率连续小波、欠采样框架、时域；它们描述原版相对曲线的处理方法，不等同于新标准压缩器的四种压扩类型。
原七点频率为 95、200、400、800、1600、3400、7500；默认七点系数均为 0，原时间常数为 0.22 s。
原曲线的正系数增强高于自身历史背景的部分，负系数抑制这部分，0 表示不增减动态控制增益；系数不是 dB、固定压缩比或固定 dBFS 阈值。
原时间常数用于跟踪背景平均水平；与本轮新增的攻击、保持、释放是不同的参数。
保留已经保存的原粒度 Float，不将用户的 0 档或 2 档统一改为另一档。界面缺失值遵循原 XML 的 0 档；已有设备配置继续恢复其实际保存值。
专业总开关、核心、限量、时间、检测、干湿、输出、侧链、前瞻、电平、诊断图、真实频率映射均默认关闭；引擎默认选择原相对曲线。
关闭专业模式使用原版处理。专业模式开启但所有新增声音分组关闭，仍保留对应原版基础声音；选择标准引擎属于用户主动切换。
多个模块同时开启时仍按现有音频链顺序叠加，独立保存不表示听感互不影响。

二、核心曲线精调与兼容频率映射
相对曲线模式的核心精调默认关闭，以当前保存的原七点曲线为基础，而不是覆盖或重写原曲线。
七点分别提供频率修正与系数修正：频率修正 −20000.000–20000.000 Hz，精度 0.001 Hz；系数修正 −2.400–2.400，精度 0.001。
总作用强度 0.0–200.0%，默认 100.0%；用于缩放原相对控制增益，不是直接放大输入音量。
频率修正归零即恢复当前基础点频率，系数修正归零即恢复当前基础系数。最终实际系数限制在原算法的有效范围；保存的请求修正不因安全限制永久改写。
手动输入后各请求点必须正值、升序且低于 24000 Hz；切换基础配置可保留专业修正，驱动按当前处理采样率重新安全约束实际节点，状态区显示实际值。
原实现存在历史频率映射比例。本轮默认保留该映射，尤其不在原非零曲线基础上悄悄改变声音。
另提供“真实频率映射”，默认关闭，只在相对曲线和核心组开启时有效。开启后使用校准到实际 Hz 的频率映射；已有非零曲线听感可能改变，需主动试听。
在真实频率映射关闭、保留兼容映射时，原七点数字是原版曲线节点参数，不能保证等于动态控制实际作用的中心频率。
诊断图统一使用实际 Hz 表示当前控制增益；它不是静态 EQ 传递频响，也不是声学测量。
限量组单独默认关闭：最大提升量 0.0–24.0 dB，默认 12.0 dB；最大衰减量 0.0–48.0 dB，默认 24.0 dB。
只有开启限量组时才应用新上下限；关闭后保持原版限量行为。标准向上压缩只开放最大提升，其他标准类型只开放最大衰减；相对曲线两项均有效。限量指模块动态控制增益，不承诺后续链路或最终输出绝不削波。

三、时间与瞬态
时间组默认关闭。背景跟随时间修正 −2000.0–2000.0 ms，默认 0.0 ms；叠加到当前原时间常数，实际背景跟随限制为 1–4000 ms。
相对模式开启时间组后，旧时间常数置灰但保存值仍作为基础；关闭后恢复原时间常数可调。
攻击时间 0.1–200.0 ms，默认 10.0 ms；保持时间 0–500 ms，默认 0；释放时间 10–2000 ms，默认 250 ms。
这些参数实际控制动态增益包络，不是将原时间常数换一个标签。相对模式作用于各处理频点的控制增益，标准模式作用于标准检测得到的目标增益。
攻击表示作用量趋向更大或改变符号时的平滑，保持在回落前暂留，释放控制回到较小作用量的速度；攻击与释放使用一阶平滑约定。
频域模式按其分析帧更新，界面显示实际更新间隔。输入较小毫秒值不代表能够突破分析帧的真实响应间隔。
标准模式关闭时间组时使用固定 10 ms 攻击、0 ms 保持、250 ms 释放；这些独立于旧背景时间，运行状态显示实际值。

四、检测与作用范围
相对检测组默认关闭，新增相对触发差值 0.0–24.0 dB，默认 0；相对软拐点宽度 0.0–24.0 dB，默认 0。
相对触发差值表示当前频带电平高于自身历史平均值多少 dB 后开始作用，不是 dBFS，也不是最终峰值阈值。
拐点为 0 时硬过渡；大于 0 时在阈值附近渐进进入作用，曲线系数决定增强或抑制方向。
弱信号保护电平 −100.0–−30.0 dBFS，默认 −80.0 dBFS；低于保护电平停止相对动态作用，保留原声，不是噪声门静音。
左右检测可选原版平均或较强声道；左右始终共用动态控制，减少左右独立调节引起的声像摆动。
处理频段下限／上限各保存 0 或 20–20000 Hz；0 表示对应端不限制，两个非零时下限必须低于上限。
相对模式限制控制增益作用的频点，标准模式通过真实频段残差路径限制被压扩的信号部分。
处理范围不同于检测侧链滤波：前者改变哪些声音被处理，后者只改变触发判断。标准模式不开放无效的相对阈值和相对拐点。标准弱信号保护仅在向上压缩且检测组开启时有效：低于保护电平停止增强并保留原声，避免将极低底噪继续抬高。标准向下压缩、向下扩展和噪声门不使用此保护值；向下扩展与噪声门在极低电平仍继续衰减，不因弱信号保护返回原声。

五、标准压扩与前瞻扩展
标准引擎是本轮新增的独立处理选择，默认不启用；与原七点相对曲线二选一，不将原系数冒充标准阈值和比率。
专业模式下选择标准引擎，旧七点曲线、时间常数、粒度和原四算法模式均置灰，后台保存值保留；切回原相对模式或关闭专业模式后按各分组规则恢复。
标准核心组开启时执行所选标准压扩；核心组关闭时不施加标准压扩目标增益。
提供四类真实压扩：
1. 向下压缩：超过固定阈值的部分按比率降低。
2. 向上压缩：低于固定阈值的部分按比率向上收拢，需留意噪声及峰值余量，建议启用最大提升量限制。低于 −100 dBFS 时固有保护停止提升，检测组开启后另使用所选弱信号保护电平。
3. 向下扩展：低于固定阈值的部分继续降低，减少背景声而保留较强声音。
4. 噪声门：根据开关阈值、回差、保持与释放打开或衰减，不使用虚假的无限大比率滑杆。
固定阈值 −80.0–0.0 dBFS，默认 −18.0 dBFS；比率 1.00:1–20.00:1，默认 2.00:1；标准软拐点 0.0–24.0 dB，默认 6.0 dB。
标准比率中 2:1／4:1 具有实际静态压扩斜率含义；噪声门模式比率置灰，保存值保留。
峰值或 RMS 检测，默认 RMS；RMS 使用实际时间窗，窗口 1–100 ms，默认 20 ms。峰值模式下 RMS 时间窗置灰。
检测侧链组默认关闭：低切保存 0 或 20–1000 Hz，高切保存 0 或 500–20000 Hz；0 表示旁路，两者开启时低切须低于高切。
侧链滤波仅改变标准检测信号，不直接把输入音色整体低切或高切；实际频率受处理采样率安全限制。
前瞻组默认关闭：前瞻时间 0.0–20.0 ms，精度 0.1 ms，默认 0。开启时检测当前输入、处理延迟后的声音，实际延迟显示为采样数。
前瞻会增加延迟，不能宣称为零延迟处理，也不自动代替最终限幅器。
噪声门回差 0.0–12.0 dB，默认 3.0 dB；仅在噪声门模式开放，阈值用于开启，阈值减回差用于关闭，减少阈值附近抖动。限量组关闭时门关闭目标为 60 dB 衰减；开启时使用最大衰减量作为关门深度，工厂方案为 48 dB。它不是数字完全静音。
标准引擎的频段、增益限量、时间、干湿与输出按各自分组生效。标准核心、侧链、前瞻均有明确开关；无效参数置灰，不能借输入框绕过。

六、干湿与输出
效果比例 0.0–100.0%，精度 0.1%，默认 100.0%；干湿组关闭时使用完整处理声。
0% 使用按当前模式实际固定延迟对齐的输入，100% 使用处理结果，中间线性混合。前瞻额外延迟同时计入干声对齐。
原算法的滤波相位可能随频率变化，固定延迟对齐不等于任意素材完全相位匹配，中间比例可能改变音色。
模块输出增益 −24.0–0.0 dB，精度 0.1 dB，默认 0；输出组默认关闭，开启后作用于混合结果。
效果差分表示完整处理结果减去对齐输入，包含动态增益、滤波相位和残差，不等于从歌曲中分离出来的纯鼓点或噪声。

七、交互与独立预设
所有有效数值支持滑杆、直接输入、加减和单项复位；分组关闭、专业模式关闭或当前算法无效时置灰，已经打开的输入框也不能继续写入禁用项。
被接管的旧参数置灰，并说明由哪个新组接管；关闭接管分组恢复可调。标准引擎选择本身接管旧四参数，直到切回相对引擎或关闭专业模式。
复位频率、系数、背景时间修正时归零，即回到当前保存基础值；总强度、标准阈值、比率、时间、滤波、比例与增益等独立参数回到其显示的中性／默认值。
关闭分组保留请求参数，重新开启恢复，不改写旧基础值；切换频率／模式只限制实际值，不永久覆盖请求值。

八、试听与电平诊断
试听提供正常处理、对齐原声、效果、差分、快照 A、快照 B 与 A/B 测量。只比较本模块，不绕过或关闭音频链中的其他模块。
A/B 使用同一输入与独立处理状态，先预热再测量 2 秒 RMS，作固定衰减匹配；不持续追踪、不自动提升音量，不是 LUFS 匹配。
信号不足不建立匹配。修改声音参数清除当前试听与匹配，但保留已保存快照，便于保存 B；收起、离页、暂停、驱动失效、关闭模块／会话或采样率变化清除全部临时试听。
仅切换电平或诊断图不改动声音，不清除已经完成的比较；工具状态不写入个人收藏或设备配置。
电平工具默认关闭，显示输入／输出左右采样峰值和 RMS、超限帧、当前最大提升与衰减、检测电平、门开关状态、对齐延迟和实际更新间隔。
这些是模块内部采样电平，不是耳内声压、真峰值或 LUFS；后续效果和输出限制器仍可能改变最终声音。
实时频段图默认关闭，显示实际频率下当前动态控制增益、对应系数、检测／背景电平及作用频段；随着音乐变化而更新。
诊断图不是静态频响、不是总输出频谱，也不是房间或耳机测量；标准引擎曲线为其当前控制状态，不把控制增益图当作固定 EQ。
状态与诊断图通过同一组合快照读取，避免预设切换时混列新旧数据。

九、稳定性与验证边界
完整参数包提交原基础与新设置；预设、粒度、算法或引擎改变时准备新状态、预热、渐变交接，连续快速更新采用最新请求，不依靠不断清空播放状态。
采样率变化重新配置实际频率、帧间隔、RMS 时间窗和延迟，保留保存请求；相同设置重发不无条件重置历史。
旧曲线字符串与原音频 Float 曲线包均完整校验，错误曲线拒绝并保留上次有效状态，避免崩溃、频率除零或整份配置静默回退。无效原曲线不能保存／覆盖或建立试听快照，界面明确提示，应用有效预设仍可修复。旧曲线编辑保留自定义频率，取消恢复原字符串；专业接管或外部曲线更新后，旧对话框不再回写。
原时间常数、粒度和算法同样检查保存类型、有限值与范围；无效基础不会被默认值替代，也不会触发音频引擎恢复循环。基础无效时仍允许关闭模块，只有实际关闭传输失败才重试。
