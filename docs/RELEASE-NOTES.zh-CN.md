DSP音效 0.1.0-alpha7：扩展参数均衡器与 BW 修复。

- 移除顶部“幅频响应 · 48 kHz 预览”文字，固定曲线左右各留 2dp，自适应手机、平板、横屏。频率及增益刻度增加并按可用空间避让，窄带曲线增加采样密度。
- 删除“曲线 / AutoEQ”入口及旧曲线编辑器、AutoEQ 搜索和服务器设置；参数均衡器使用现有整项开关。历史曲线数据仅保留备份，不再启用。
- 增益步长新增 1.5/2 dB；增益滑杆和驱动实际支持最高 ±100 dB，Q 支持 0.1–100。设置增加 Q/频率滑杆开关，每段可直接调增益、Q 及频率；精调窗口支持 BW。
- 修复 Q/BW 切换时舍入后回算越界而不能保存的问题。切换显示保留原始 Q 精度，实际编辑才换算；每段记住 Q/BW 显示方式。Q 越大，BW 越小。
- 根据所选总频段数在 20–20000 Hz 对数均分，不重复十段。更改总数量会重新计算全部频率，保留原有各段其他参数；设置另提供“重新分布频率”以修正已有 170 段配置。单段复制/删除保留编辑语义。

**APK 与 alpha7 驱动必须配套升级。** Magisk 覆盖刷入 DSP-Audio-Driver-0.1.0-alpha7.zip 并重启，再覆盖安装 DSP-Audio-0.1.0-alpha7.apk。包名、签名和模块 ID 不变，无需卸载或清除数据。协议升级为 4，不能与 alpha6 或更早驱动混用。

已有手动频率保持原值；需要均分时执行设置中的重新分布。新导出预设要求版本码至少 1007；旧版预设可导入，但历史曲线/AutoEQ 不再执行。PEQ、JamesDSP、MSEB、ViPER 和左右平衡的处理顺序保持一致。

图像仍是按 48 kHz 计算的滤波器合成幅频响应，不含后续动态处理、MSEB、ViPER 或输出限制器；驱动使用实际采样率。±100 dB 是单段滤波参数范围，最终响度还受后续输出控制影响。

Neutron Player 仅作交互参考，Q/BW 使用公开 RBJ/W3C 数字频率校正公式，不包含 Neutron 的私有代码或资源。本轮未安装、更改或重启用户手机。构建与回归结果在发布验证后补充。
