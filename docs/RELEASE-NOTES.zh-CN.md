DSP音效 0.1.0-alpha8：修复 Q/BW 主滑杆，增加精细步长设置与实时频段标记。

- 精调窗口选择 BW 后，返回参数均衡器时，频段卡片的标签、数值和滑杆继续使用 BW；“BW 带宽”统一改名为“BW”。切换 Q/BW 保留同一滤波响应，增大 BW 会变宽，增大 Q 会变窄。修正切换、保存及频率变化时的显示换算。
- Q/BW、频率滑杆两侧增加减号和加号，按对应步长点动。主滑杆与精调窗口共同使用每段保存的 Q/BW 显示方式。
- 均衡器设置改为滑杆配右侧数值框，数值框可点击并手动输入：频段数量 1–170、增益滑块步长 0.01–2 dB、增益范围 1–100 dB（显示为 ±对应值）、Q/BW 滑块步长 0.01–100、频率滑块步长 1–1000 Hz。Q/BW 和频率的新增设置控制每次调节的步长，频段本身仍支持 Q 0.1–100、20–20000 Hz。
- 频响图增加当前频段的红色小圆点，旁边实时显示频率和增益；没有增益参数的滤波类型显示 0 dB。靠近边缘时标签避让，超出当前显示增益范围时仍保留真实数值。曲线线宽从 2.5dp 改为 1.25dp。

**已使用 alpha7 驱动的用户只需覆盖安装 alpha8 APK，无需为本次界面修复重刷驱动或重启。** 本次不改变 DSP 算法、音频参数范围或协议，协议仍为 4；alpha7/alpha8 驱动均可与 alpha8 APK 配合。首次安装或从 alpha6 及更早版本升级时，安装 alpha8 驱动并重启，再覆盖安装 APK。包名、签名、模块 ID 不变，无需清除数据。

旧预设仍可导入，已有调音参数和频率不会因更新自动重排。新增步长字段缺省为 Q/BW 0.01、频率 1 Hz。新导出预设要求应用版本码至少 1008，防止旧应用拒绝新的连续增益范围/步长或丢失新增设置。

保留最多 170 段、七种滤波类型、±100 dB 增益、按数量对数分布、可选 Q/BW 与频率滑杆及固定顶部曲线。更改总段数会重新分布全部频率，单独修改显示设置不会重排。PEQ → JamesDSP → MSEB → ViPER → 左右平衡的处理顺序保持一致，历史曲线/AutoEQ 继续停用并保留旧数据备份。
