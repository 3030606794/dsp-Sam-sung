DSP音效 0.1.0-alpha9：七类均衡器滤波器均支持增益，优化实时曲线，新增独立 PEQ 预设收藏，更新调节、定位与重置控件。

- 七类滤波器均可调节真实增益。低通、高通、带阻、带通在保持频率/Q 形状的基础上，对滤波输出施加所设增益；0 dB 不会旁路这些滤波器。峰值和架式原有增益行为保持不变。
- 设置中的增益、Q/BW、频率步长只控制加减按钮；拖动滑杆分别使用 0.01 dB、0.001、1 Hz 精度，不再受按钮步长影响。精调增益输入限制在当前所选的 ±增益范围内；缩小范围不会自动裁剪已保存的增益。
- 增益滑杆按当前数值显示颜色：正增益为红色、负增益为蓝色、0 dB 恢复主题原色；滑块、已调节轨道和触控光晕同步变化。
- 右上角可切换频响图固定顶部或随频段列表滚动隐藏，偏好随设备配置和预设保存。底栏固定提供设置、预设、添加频段和重置入口，170 段列表继续复用可见行。
- 每张频段卡片顶部居中增加“定位频段”按钮，点击后展开未固定的图表，显示该频段红点、频率/增益文字和 XY 定位线 2 秒，不改变参数。拖动时标记持续显示，松手或点动加减后 2 秒隐藏。
- 红点更小、更淡，标签字体缩小，并显示 Q 和 BW（支持 BW 的类型）；去掉界面的“倍频程”字样，背景网格线减细。
- 拖动时取消曲线过渡动画，合并连续计算请求并复用未改变频段的响应，降低曲线追赶滑杆的延迟；红点直接随最新参数更新。
- 重置可选择 Q、频率、增益或全部三项。Q 恢复默认约 0.7071，频率按现有段数在 20–20000 Hz 对数分布，增益归零；段数、ID、滤波类型、启用状态和显示设置保留。
- 新增独立 PEQ 收藏库，最多 20 个预设，支持保存当前参数、应用、改名、覆盖、删除、JSON 导入和单项/全部导出。收藏库保存在应用私有目录，不随设备切换或全局预设替换；可将导出的 UTF-8 JSON 保存在外部位置备份。导入先验证全部参数及容量，重名自动加序号，不覆盖已有收藏；应用预设不自动开启音效。
- “添加频段”和批量增加的新频段初始均为峰值、0 Hz、0 dB、Q 0.5。0 Hz 是未设置标记，暂不参与滤波，选择 20–20000 Hz 后生效；默认频段组和各类重置保持原有语义。传给驱动时使用禁用的 20 Hz 占位，无需再次修改驱动协议。
- 调整频段数量默认保留已有频率，可选择从前端或后端增加/删除，默认后端。确认框显示原数量、目标数量和增删段数，例如“11 → 47 段，增加 36 段”；只有主动开启“重新分布频率”时，才把调整后的全部频率按对数分布到 20 Hz–20 kHz。取消不会改动参数。

**本次必须同时升级 alpha9 APK 和 alpha9 驱动，并重启加载新驱动。** 驱动协议升级为 5，防止旧驱动静默忽略低通、高通、带阻、带通的增益；alpha7/alpha8 协议 4 驱动不能与本版 APK 混用。音频参数范围、包名、签名和模块 ID 不变。

原有设备/全局预设仍可导入，已有频率不自动重排。旧 PEQ JSON schema 1 中，低通、高通、带阻、带通此前被忽略的隐藏增益迁移为 0 dB，以保留原有声音；其他调音参数不变，读取不回写原配置，后续保存使用 schema 2。旧配置未保存固定偏好时默认固定顶部；未保存按钮步长时，Q/BW 为 0.01、频率为 1 Hz。新导出的设备/全局预设最低应用版本码为 1009，避免旧应用误读新的增益语义或丢失显示设置。

独立 PEQ 收藏使用本应用的 `dsp-audio-peq-presets` version 1 格式，单项和整库导出格式一致；不保证直接导入 Neutron 的预设格式。详见 [PEQ 预设格式与备份](PEQ-PRESETS.zh-CN.md)。

保留 Q/BW 模式保存与正确方向、最多 170 段、七种滤波类型、Q 0.1–100、20–20000 Hz、±100 dB，以及 PEQ → JamesDSP → MSEB → ViPER → 左右平衡的处理顺序。图表仍是按 48 kHz 计算的 PEQ 合成响应，红点表示当前频段设定值；不表示整条处理链的实时输出。
