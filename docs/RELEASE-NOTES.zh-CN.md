DSP音效 0.1.0-alpha6：最多 170 段的参数均衡器。

- 参数均衡器替换原“幅度响应”编辑入口，响应预览固定在顶部，下方频段列表独立滚动。
- 最多 170 个独立滤波段，支持峰值 EQ、低架、高架、低通、高通、带阻、带通；可精调频率、Q，以及适用类型的增益和 BW。
- 可设置频段数量、滑杆步值 0.1/0.25/0.5/1 dB、增益显示范围 ±6/12/18/24 dB。调整显示范围不会改写已有增益。减少频段前确认。
- 沿用原 DSP 配色、Material 滑杆及动画。没有声道选择或额外波德图设置；仍显示顶部合成响应预览（按 48 kHz 计算，滤波器预览不包含后续音效/限制器）。
- 原曲线、AutoEQ 和文本导入入口保留；有旧曲线时升级后继续使用旧曲线，点击“使用参数均衡器”才切换。切换模式或编辑参数不自动启用音效，主页开关仍控制当前模式。

**本版需要 APK 与 alpha6 驱动配套升级。** Magisk 中覆盖刷入 DSP-Audio-Driver-0.1.0-alpha6.zip 并重启，再覆盖安装 DSP-Audio-0.1.0-alpha6.apk。包名、签名、模块 ID 保持不变，预设和其他音效参数继续保留。alpha4 驱动不能提供本版 PEQ；回退应同时恢复旧 APK 与对应驱动。

新 PEQ 为独立实现，Neutron Player 2.29.0 仅作为界面交互参考，不含其中的代码、私有库或图像。滤波器使用公开 RBJ 二阶节公式；处理链为 PEQ → JamesDSP → MSEB → ViPER → 左右平衡，不占用 DDC 或 LiveProg。

本轮未替用户安装或更改手机状态；实际设备上的界面、试听和满负载表现由用户安装后验证。构建、音频及界面回归的结果会在发布时补充。
