DSP音效 0.1.0-alpha12：修复实时可编程 DSP 闪退，新增均衡器多选编辑与快捷跳转。

- 修复 alpha11 在打开或选择内置脚本时的闪退。手机日志确认，中文参数显示使用的正则表达式被 Android ICU 拒绝，抛出 PatternSyntaxException。现改为直接读取列表选项的成对分隔符，不再依赖该正则表达式。
- 保留内置脚本中文名称、参数和选项。动态低音初始及重置强度仍为 5%；已保存参数、自定义脚本和均衡器预设保留。
- 增加参数翻译与原始属性一致性回归，并将真实 Android 运行环境的脚本解析检查纳入发布验证，覆盖电脑 JVM 与手机正则行为的差异。

- 频段标题行按五个等宽区域排列，定位图标固定居中，不随未设置提示或增益数字移动。类型文字缩小点击范围；右侧新增排序手柄，长按可上下拖动，序号随新位置实时更新，参数随原频段完整移动，松手保存；编辑模式禁止排序。
- 底部新增“编辑”：点击卡片空白处多选并高亮，可在“选中频段／排除选中频段”之间切换操作范围。批量 Q、BW、滤波器类型、重置和频率重新分布仅作用于该范围，保存/覆盖预设只收录该范围内的频段。
- 编辑模式支持删除选中或未选中的频段，确认显示删除及剩余数量，至少保留 1 段；全选时仍可设置或保存，但不能全删。数量、设置控件和添加入口同步，新增不会自动选中。旋转和滚动按稳定 ID 保留选择，退出编辑恢复全体操作。
- “频段·前／频段·后”单击添加一段，双击跳到顶部/末尾，长按选择添加数量；双击不误添加。添加、跳转、长按及容量不足均有提示；达到 170 段仍可双击导航。
- 频段增益、Q/BW、频率及 MSEB 的加减按钮支持长按匀速连续调节。频段每次按所设步长变化，MSEB 每次 1 点；不随按住时长加速，松手或离开页面即停止。去掉频率输入框“0 为未设置”的说明，保留新频段的 0 Hz 数字。

APK versionCode 1012，包名、签名及数据格式不变。覆盖安装即可，无需清除数据。已安装 alpha10/alpha11 驱动时不必更新驱动，也无需重启手机；原生音频实现及协议 5 均未改变。alpha9 驱动仍可处理音效，但不提供 alpha10 新增的状态查询；alpha8 及更早驱动不兼容。

保留 alpha11 的 Q/BW 三位小数、批量参数设置、紧凑卡片、设置数值框缩小和状态栏避让等功能。允许重复频率；最多 170 个频段和 20 个独立 JSON 预设。PEQ 配置 schema 2、收藏 version 1、全局预设最低版本码 1010 均不变。
