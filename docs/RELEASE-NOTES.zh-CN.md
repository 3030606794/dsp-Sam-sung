DSP音效 0.1.0-alpha11：三位小数 Q/BW、批量参数设置、紧凑卡片及实时 DSP 中文界面。

- 精调 Q/BW 输入框和 BW 范围显示三位小数，内部保留完整 Q。反复切换模式、未修改直接确认均不因显示四舍五入而改变曲线；在 BW 模式修改频率时也沿用完整 BW 换算。
- 底部“设置、重置、预设、参数设置”四按钮等宽同排。参数设置可统一全部频段的 Q、BW 或滤波器类型，Q/BW 同时遵守所设 Q 上限；批量 BW 按各频率换算，先校验所有频段，整体应用，不部分修改。
- 重置菜单新增“按当前数量重新分布 20 Hz–20 kHz”，从设置中移除原入口，保留操作确认。重分布只改频率。
- 卡片按滑杆开关隐藏重复信息。两个滑杆都显示时标题只保留“序号 • 滤波器类型”；关闭对应滑杆后，频率或 Q/BW 才在标题下显示。点类型可直接选择滤波器。
- 设置弹窗删除冗长说明，右侧六个数值框按约 80% 比例缩小，仍可点按输入。
- 首页按实际状态栏和屏幕缺口留边，并保留小间距，修复设备卡片与状态栏重叠。
- 实时可编程 DSP 的内置脚本名称、参数和常用选项补充中文。动态低音的初始强度和恢复默认值统一为 5%，已保存的自定义数值保留；只迁移未经修改的旧内置动态低音文件，不覆盖改过的脚本。

APK versionCode 1011，包名、签名和数据格式不变，可覆盖升级，无需清除设置。本轮未改原生音频实现，已安装 alpha10 驱动可继续使用，无需为本轮 UI 修复重新刷模块。随附 alpha11 驱动与 alpha10 音频实现一致、协议仍为 5。alpha9 驱动可处理音效但不支持首页状态查询；alpha8 及更早驱动不兼容。

允许重复频率。新增段仍为峰值、0 Hz、0 dB、Q 0.5，未设置的 0 Hz 段暂不滤波。保留最多 20 个 JSON 预设、所有类型增益、步长只用于加减按钮及实时图表交互。全局预设最低版本码仍为 1010；PEQ 配置 schema 2、收藏 version 1 不变。

处理采样率由系统音频路径决定，驱动支持 8–192 kHz。图表仍为 48 kHz 参考下的 PEQ 合成响应，不代表整条 DSP 链或 DAC 最终输出。手机显示、听感及各音频路径由用户安装后验收。
