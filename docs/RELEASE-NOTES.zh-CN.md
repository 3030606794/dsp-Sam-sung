DSP音效 0.1.0-alpha10：紧凑均衡器、前后批量添加、统一 Q/BW 限制及真实驱动状态。

- 底部“设置、重置、预设”三个按钮等宽同排。添加移至图下方“+频段•前 / +频段•后”：点按加一段，长按可选 5、10、15、20 或自定义，最多 170 段，不重排已有频率。
- 频段卡片压缩高度，定位图标与未设频率的 ! 提示并列在标题中间；点增益、Q/BW 或频率数值直接进入对应精调输入框。
- 七种滤波器均可切换 Q/BW，模式切换保持实际 Q；新增 Q 范围上限 0.1–100，滑杆、加减按钮和手动输入共同受限，BW 边界随频率按同一 Q 范围换算。缩小上限不自动改写原有参数，后续精调需输入范围内的值。旧配置默认 Q 上限 100。
- 图表标签只显示当前频段使用的 Q 或 BW。XY 辅助线加粗至与响应曲线一致，增益轴和频率轴端点新增随动红点；沿用拖动实时更新、结束 2 秒隐藏。
- 重置增加“重置所有滤波器类型”，恢复峰值；“全部重置”也包括滤波器类型。重置 Q 默认约 0.7071，若上限更低则取所设上限。
- 首页去掉“DSP音效”和“输出控制”标题，紧凑显示驱动、设备与处理采样率。驱动新增可选只读状态查询，报告音效宿主实际配置采样率和处理活动，不冒用 James 内部采样率或 PEQ 48 kHz 参考值。

本版仍为驱动协议 5。alpha9 驱动可继续处理音效，但不能提供新状态查询；要完整显示新信息，请安装 alpha10 驱动并重启。alpha7/alpha8 及更早驱动仍不兼容。包名、签名和模块 ID 不变，可覆盖升级，无需清除设置。

手机系统决定音频路由与输出采样率，本应用没有强制设置 USB 采样率的接口。融合驱动支持 8–192 kHz；显示的处理采样率是音效所在路径，不能当作 DAC 最终硬件输出率。USB 独占或直通可能绕过系统音效。

允许重复频率。新增仍为峰值、0 Hz、0 dB、Q 0.5，0 Hz 未设置段暂不滤波。保留最多 20 个 JSON 预设、原有步长/颜色反馈与增益限制。新导出的全局预设最低版本码 1010，以保留 Q 范围设置。旧预设可导入；PEQ 配置 schema 2、收藏 version 1 不变。

图表仍为 48 kHz 下的 PEQ 合成响应，未代表整条 DSP 链实际输出。手机听感及各音频路径需安装后验收。
