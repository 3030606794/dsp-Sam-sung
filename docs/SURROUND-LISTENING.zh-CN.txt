扬声器串音抵消 — 小范围第二轮 ui26

基线：ui25 / 0b2ed28；应用0.1.0-alpha12-surroundtools-ui26 / 1039。
驱动0.1.0-alpha12-surroundtools / 1039；协议5、能力262143，新增能力131072。
仅实现用户明确列出的三项：等响度A/B、校准试听、相位与时间诊断。
第一轮所有功能、主页独立开关和折叠、八个编号槽、最多20项独立预设库保留。

1. 等响度A/B试听（默认关闭）
先保存A/B快照，再分别试听两组，建议使用同一段音乐测量。
每组先等待滤波切换结束及500ms稳定期，再累积500～10000ms的双声道功率。
比值为本模块正常输出功率/本模块输入功率，包含该快照现有动态RMS与采样峰值处理。
电平匹配不依赖第一轮监测开关；静音/过低信号不保存测量，等待有效信号重新测量。
A/B都完成后，选择相对输入增益较低的一组为参考，另一组仅衰减，范围0～12dB，默认最多6dB。
超过最大衰减时明确提示尚未完全等响。固定补偿使用20ms平滑进入/退出，完成后不再跟随音乐更新。
这是模块内RMS相对电平比较，不是LUFS或到耳响度测量，也不保证不同片段主观等响。
两组快照、测量结果、固定补偿和触发编号只保留在内存，不写设备参数或预设库。
清除测量、更新任一A/B快照、测量设置改变或驱动重置后需重新测量。
离页销毁快照；暂停、切槽、音频编辑、关闭模块/总开关或会话失效退出试听并恢复保存参数。

2. 校准试听工具（默认关闭）
“允许手动校准试听”只允许按钮，不自动发声。每次必须显式点击“开始校准试听”。
四种信号：左声道正弦、右声道正弦、居中单声道正弦、居中带限噪声。
信号峰值−60～−12dBFS，默认−30dBFS；正弦20～16000Hz，默认1000Hz。
噪声低频20～16000Hz、高频21～20000Hz，默认200～8000Hz，要求低频小于高频。
噪声为固定种子均匀白噪声经过一阶高/低通带限，源峰值受限；不声称粉红噪声或砖墙滤波。
试听1000～30000ms，默认5000ms；淡入淡出20～500ms，默认100ms。
在RACE输入处替换音乐并淡入/淡出，不叠加；原声道音量/前级及后续音效仍参与。
正弦频率不超过实际宿主采样率45%；噪声两边界按比例缩小并报告实际目标。
需要音乐播放以维持正在处理的会话，本工具不自行创建播放器、不打开任何音效或设备开关。
计时按实际处理样本推进；应用250ms会话轮询在处理停止时取消请求。
停止、到时、暂停页面、离页、切槽、音频参数编辑、关闭模块/总开关、采样率重配置或重置均退出。
每次启动使用新的临时触发编号；重复发送或停用后的旧编号不得再次启动。
源信号峰值不等于后续音效及设备最终输出峰值；第一轮峰值保护保持用户原设置。

3. 相位与时间响应诊断（默认关闭）
展开相位、群延迟和脉冲响应均绘制完整2×2矩阵的LL/RR/LR/RL四条路径。
相位/群延迟为20Hz到min(20kHz,宿主采样率45%)；幅度低于−120dB的路径不绘制相位。
群延迟按复数频率导数计算，可呈现负值，不强行截断。
脉冲响应显示1～100ms，默认20ms，用时间递推计算，避免短FFT窗口的循环尾部污染。
线性模型包含原/专业抵消、独立双向衰减和分数延迟、Butterworth斜率、混合及静态输入/输出校准。
不包含动态RMS、采样峰值保护、临时等响度增益、测试信号生成或后续DSP。
优先活动会话的实际RACE采样率；未知时明确使用48kHz参考。
显示最大双声道能量频率增益的网格估算（矩阵最大奇异值），供电平余量参考。
网格估算不保证连续频率最大值、任意信号采样峰值、真峰值或最终设备余量。
图表不是房间实测，也不能换算到耳串音减少dB。后台计算可取消，关闭诊断不继续计算。

保存与兼容
第二轮新增14项设置（9个数值、3个开关、2个选择），均使用各槽slot_N_pro_KEY整数。
数字输入、加减微调、可见单项复位沿用第一轮；枚举提供单项复位。
旧四项及第一轮专业键/精度不迁移。只含旧四项导出v1，只含第一轮新项导出v2，含本轮设置导出v3。
v1/v2/v3均可读取，单位仍schema-1-scaled-integers；错误/未知字段和越界整批拒绝。
导入旧参数清除当前槽缺失的新项，恢复默认关闭，不改其他槽、模块开关或编号。
含第二轮键的整体配置最低应用1039；旧第一轮键仍最低1038。
旧驱动仅发送其支持的旧包；本轮配置保留、提示升级。诊断是应用侧预测，可单独查看。
默认立体声增强.irs、原D源、内置内容与删除/覆盖保护完全保留。

新增协议（旧27字SET和32字GET不变）
SET196612：严格13个int32 / 52字节。
0 schema1；1匹配开关；2最大衰减0.1dB；3测量ms；4比较epoch正整数；5临时校准0停止/1左/2右/3居中/4噪声；
6源峰值0.1dBFS；7正弦Hz；8/9噪声低/高Hz；10持续ms；11淡化ms；12临时启动token（停止为0）。
GET131218：严格24个int32 / 96字节，reply总112字节。
0 schema1；1偶数快照epoch；2采样率；3模块实际启用；4实际试听0～4；5匹配开关；6/7 A/B测量有效；
8/9 A/B相对输入电平milli-dB（无效INT32_MIN）；10/11固定增益milli-dB；12实际平滑试听增益milli-dB；
13当前测量目标0/3/4；14进度0～1000；15实际校准模式0～4；16剩余ms；17/18有效噪声边界；
19比较epoch；20达到衰减上限；21信号过低；22有效正弦Hz；23已接收校准token。
快照由音频线程原子发布，读取竞争返回EAGAIN；无音频回调动态内存分配。
