# DSP音效 0.1.0-alpha6：升级与兼容性

## 安装和升级

alpha6 APK 与 alpha6 驱动使用协议 3，需要成对升级；alpha4/alpha5 APK 与 alpha4 驱动使用协议 2，不能与本版混用。

1. 在 Magisk 覆盖安装 `DSP-Audio-Driver-0.1.0-alpha6.zip`，然后重启。
2. 覆盖安装 `DSP-Audio-0.1.0-alpha6.apk`。包名 `com.dspfusion.android`、签名、模块 ID `dsp_fusion` 不变，无需卸载或清除设置。
3. 原 JamesDSP、ViPER RE/Fork/AIDL、AML 模块继续禁用。本融合模块提供一个公开音效实例和一份 `libdspfusion.so`。

首次安装也需先禁用上述独立音效模块并重启。安装器仅修改 Magisk 模块中的配置副本。支持 Android 8+、ARM64/ARMv7，需 root。

## 参数均衡器与旧曲线

新增独立 IIR 参数均衡器，最多 170 个双声道共用参数的二阶滤波段，不提供声道单独编辑。频率范围 20–20000 Hz，Q 为 0.1–30，峰值/低架/高架增益为 ±24 dB；低通、高通、带阻、带通不使用增益参数。带通采用中心峰值 0 dB 形式。

可选滑杆步值 0.1/0.25/0.5/1 dB、显示增益范围 ±6/12/18/24 dB。改变显示设置不会裁剪已保存数值。默认十段零增益峰值滤波，频段参数和主页整项开关分开保存；编辑界面不自动启用效果。

顶部固定曲线按 48 kHz 显示参数滤波器的合成响应；不包含后续 MSEB、ViPER、动态处理或限制器。BW 按 48 kHz 换算成 Q 后保存，峰值/带阻/带通可用，其他类型使用 Q。驱动按实际采样率重新计算系数；频率达到或超过实际采样率一半的段暂时旁路，保存的参数不被改写。

旧“幅度响应”数据完整留在原配置中。有旧曲线的配置升级后继续使用旧模式；没有旧曲线则进入新参数均衡器。新界面的“使用参数均衡器”和旧编辑页的“使用此曲线”仅切换模式，不改变主页开关。两种模式互斥，不把旧频率/增益节点误转换成峰值 EQ；原 AutoEQ 和文本编辑仍在“旧曲线 / 曲线·AutoEQ”入口。

新 PEQ 参数与模式存入现有 `dsp_graphiceq` 命名空间，随设备配置和预设保存。包含新 PEQ 数据的导出预设要求应用版本码至少 1006；旧预设仍可导入，不会保留此前配置的隐藏 PEQ 数据。回退旧版前可另存预设；旧版不能表达新滤波器设置。

## 其他功能与处理顺序

处理顺序为 **PEQ → JamesDSP → MSEB → ViPER → 左右平衡**。新参数均衡器不占用 DDC、卷积或 LiveProg 通道。James 的原有输出控制仍可调限制器阈值、释放及后增益；左右平衡继续位于整条链末端。

沿用 alpha4 的连续音频块、卷积分片校验、交叉反馈初始化、AnalogX 模式切换修复；沿用 alpha5 的 MSEB 每次 ±1/双击归零、独立展开与启用、ViPER 对应图标、合并的固定输出卡。

MSEB 仍是独立实现的海贝式听感近似，Neutron 仅作本次 UI 参考，不使用其私有音频代码或图像。

## 回退与验证范围

回退至 alpha5：恢复 alpha4 驱动并重启，再恢复 alpha5 APK；Android 降级安装可能需要先导出预设再卸载。回退至原 JamesDSP/ViPER：禁用融合模块，重新启用原模块并重启，再使用原应用。

170 段是支持上限，处理开销随有效滤波段数增加；零增益峰值/架式段会跳过运算。自动测试验证数值稳定性、跨块连续处理、参数更新和界面交互；主机性能测试不能代表手机实时负载。USB 独占、直通及具体 AIDL/HAL 路由的处理效果仍需用户在设备上试听确认。
