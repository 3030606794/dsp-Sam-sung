# DSP音效 0.1.0-alpha9：升级与兼容性

## 安装和升级

**必须同时安装 `DSP-Audio-0.1.0-alpha9.apk` 和 `DSP-Audio-Driver-0.1.0-alpha9.zip`，并重启加载新驱动。** 本次低通、高通、带阻和带通开始支持真实输出增益，协议升级为 5；应用会拒绝旧协议驱动，避免界面已改变增益而音频仍忽略增益的情况。

alpha7/alpha8 使用协议 4，alpha6 使用协议 3，alpha4/alpha5 使用协议 2，均不能与 alpha9 APK 混用；旧 APK 也不能使用协议 5 驱动。

1. 在 Magisk 安装 `DSP-Audio-Driver-0.1.0-alpha9.zip`，然后重启；已有 alpha7/alpha8 驱动也必须更新。
2. 覆盖安装 `DSP-Audio-0.1.0-alpha9.apk`。包名 `com.dspfusion.android`、签名、模块 ID `dsp_fusion` 不变，无需卸载或清除设置。
3. 原 JamesDSP、ViPER RE/Fork/AIDL、AML 模块继续禁用。融合模块提供一个公开音效实例和一份 `libdspfusion.so`。

首次安装也需先禁用上述独立模块并重启。安装器仅修改 Magisk 模块中的配置副本。支持 Android 8+、ARM64/ARMv7，需 root。

## 参数均衡器与旧数据

最多 170 个双声道共用的二阶滤波段。频率 20–20000 Hz，Q 为 0.1–100，七类滤波器均支持 ±100 dB 增益。峰值/低架/高架维持原有增益定义；低通、高通、带阻、带通在原有滤波输出上乘以 `10^(gain/20)`，频率/Q 形状保持不变。带通中心增益等于设定增益；四类滤波器在 0 dB 时仍执行滤波。

均衡器设置使用滑杆与可手动输入的右侧数值框：频段数量 1–170，增益按钮步长 0.01–2 dB，增益范围 1–100 dB（图表和滑杆显示 ±对应值），Q/BW 按钮步长 0.01–100，频率按钮步长 1–1000 Hz。步长设置只作用于加减按钮；拖动增益、Q/BW、频率滑杆分别按 0.01 dB、0.001、1 Hz 调节，不改变实际参数的允许范围。精调增益输入也限制在当前增益范围内；缩小范围不自动裁剪已有增益。

可显示每段 Q/BW 和频率滑杆，两侧减号、加号按设置的步长调节。每段记住 Q/BW 显示方式，精调窗口确定后主界面继续使用相同标签、数值和滑杆。编辑、展开、显示设置均不自动启用音效，主页右侧开关独立控制。

默认频段组按数量在 20–20000 Hz 对数均分。数量为 1 时使用几何中心频率；数量大于 1 时首末段为 20/20000 Hz。更改设置中的总数量会先显示确认框，列出原数量、目标数量和实际增删段数；可从前端或后端增加/删除，默认后端。默认保留所有剩余频段的频率、ID、类型、增益、Q 和启用状态，不重新计算频率。仅在开启“重新分布频率”后，才将调整后全部频率按上述规则重排。取消不会改动参数。单段复制、添加、删除也不强制改写其余段；已有 alpha6 或手动调音不自动重排，仍可使用独立的“重新分布频率”按钮明确执行。

“添加频段”按钮和批量增加的新频段均使用初值：峰值（PEAK）、0 Hz、0 dB、Q 0.5。批量调整若选择重新分布，新增段频率也会按总段数重排；未选择时保留 0 Hz。0 Hz 表示频率未设置，存储时保留 0，曲线和音频均跳过该段；设置为有效的 20–20000 Hz 后才参与处理。传输时将其编码为禁用的 20 Hz 占位段，不向驱动发送 0 Hz，也不改变保存的启用状态。此行为无需额外修改驱动或提升协议；alpha9 仍要求协议 5。默认频段组和重置的原有 Q/频率语义不变。

右上角按钮切换曲线固定顶部或随列表滚动隐藏，底栏设置、预设、添加和重置入口始终可用。曲线左右各留 2dp，线宽为 1.25dp，按 48 kHz 显示参数滤波器的合成幅频响应，不包含后续 MSEB、ViPER、动态处理或限制器。

每张频段卡片顶部居中提供“定位频段”按钮，点击后展开未固定的图表，显示该频段的红点、频率/增益/Q/BW 文字（BW 仅支持的类型）和 XY 定位线 2 秒，不改变参数。拖动滑杆期间标记持续显示，松手或点动加减后 2 秒隐藏。红点半径 3dp、透明淡化，标签 9sp，网格线 0.5dp。所有滤波类型均显示实际增益设定；红点表示频段设定值，不表示多段叠加后的增益。超出图表增益范围时点停在边缘、标签保留真实数值，边界标签会避让。

拖动参数时立即更新红点并取消曲线过渡动画；预览计算合并连续请求，复用未改变频段的响应，保持原自适应采样精度。实际帧率仍取决于手机负载，不将主机测试结果视为手机帧率保证。

重置可单独针对 Q、频率或增益，也可同时重置三项。Q 恢复默认约 0.7071，频率按现有段数在 20–20000 Hz 对数均分，增益归零；保留段数、频段 ID、滤波类型、启用状态及显示设置。重置不会自动启用音效。

BW 以 octave 表示，按 48 kHz 数字频率校正换算成 Q 后保存；峰值/带阻/带通可用，其他类型使用 Q。切换 Q/BW 显示不改变原始滤波参数；增大 BW 会变宽，增大 Q 会变窄。驱动按实际采样率重新计算，频率达到或超过 Nyquist 的段暂时旁路，不改写保存值。

旧曲线/AutoEQ 功能已删除，历史字符串保留在配置中作为备份，不再执行，也不误转换成峰值滤波器。已有新 PEQ 数据继续使用；仅有历史曲线的配置进入默认零增益 PEQ。参数、固定偏好与显示开关仍保存在 `dsp_graphiceq`，随设备配置与预设保存。旧配置缺少相应字段时，默认固定顶部，Q/BW 按钮步长为 0.01、频率按钮步长为 1 Hz。

旧 PEQ JSON schema 1 中，低通、高通、带阻、带通此前未参与声音处理的隐藏增益会在读取时迁移为 0 dB，保留升级前声音；频率、Q、显示模式以及峰值/架式增益不变。读取不会改写原始 JSON；后续保存使用 schema 2，明确保存七类滤波器的新增益语义。驱动 SET 1250 的二进制包仍为 schema 1，与配置 JSON 的版本是两个独立字段。

原有设备/全局预设的新导出文件要求应用版本码至少 1009（alpha9）。alpha7/alpha8 不支持配置 schema 2 和新增滤波器增益语义，也不认识固定偏好，不能无损往返本版预设；最低版本检查会阻止旧应用导入新预设。旧预设仍可导入 alpha9；导入缺少 PEQ 数据的预设会回到默认 bank。

## 独立 PEQ 预设收藏

底栏“预设”可保存最多 20 个 PEQ 收藏，支持保存当前参数、应用、改名、以当前参数覆盖、删除、导入和导出。收藏保存全部频段及均衡器显示/步长设置，不保存或改变总音效开关；导入收藏只加入库，应用时才替换当前 PEQ 参数。覆盖与删除需要确认。

收藏位于应用私有目录的独立 `peq-presets.json`，不会因切换设备或加载设备/全局预设而被替换，也不随这些预设导出。要在清除数据或卸载前保留收藏，请另行导出单项或全部收藏到外部位置。读写失败保留原文件并提示错误，不以空库覆盖。

外部文件是 UTF-8 JSON，格式标识 `dsp-audio-peq-presets`、版本 `1`，单项和整库使用相同结构。导入在写入前验证全部内容和 20 个容量限制；任一项非法或超限均不导入。重名使用 `名称 (2)` 等序号加入，不覆盖现有收藏。这是本应用专用格式，不保证直接导入 Neutron 格式。格式、范围和示例见 [PEQ 预设说明](PEQ-PRESETS.zh-CN.md)。

## 处理与验证范围

处理顺序为 **PEQ → JamesDSP → MSEB → ViPER → 左右平衡**，不占用 DDC、卷积或 LiveProg 通道。James 输出控制继续调节限制器阈值、释放与后增益。±100 dB 是单段滤波参数范围，最终响度受后续限制器影响；超出内部数值表达能力的极端多段叠加会进行饱和保护，不回退干声。

保留此前连续音频块、卷积分片校验、交叉馈送、AnalogX 模式切换修复，以及 MSEB ±1/双击归零、独立展开启用、ViPER 图标和固定输出卡。MSEB 是独立实现的海贝式听感近似；Neutron 仅用于交互参考，没有使用其私有音频代码或图像。

170 段是支持上限，开销随有效滤波段数增加；零增益峰值/架式段跳过运算。主机性能不能代表手机实时负载；设备试听、USB 独占、直通及具体 AIDL/HAL 路由仍由用户安装后确认。

## 回退

回退 alpha8 或 alpha7 必须同时恢复对应 APK 与协议 4 驱动并重启，再恢复升级前由对应版本导出的预设；旧版无法读取 alpha9 保存的配置 schema 2，不能导入 alpha9 新预设。回退 alpha6 时同时恢复 alpha6 驱动并重启，再恢复 alpha6 APK；其 Q30/±24 dB 范围无法表达本版极值。回退旧版前另存预设，Android 降级安装可能需要卸载。回退原 JamesDSP/ViPER 时禁用融合模块，重新启用原模块并重启，再使用原应用。
