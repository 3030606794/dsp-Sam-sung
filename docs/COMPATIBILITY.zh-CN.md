# dsp音效 0.1.0-alpha5：升级与兼容性

alpha5 只更新应用界面，继续使用 alpha4 驱动（协议 2）。已使用 alpha4 的用户直接覆盖安装 DSP-Audio-0.1.0-alpha5.apk，无需重刷驱动、重启或清除设置。发布页附带的 alpha4 驱动供首次安装或从更早版本升级使用；alpha3 驱动不兼容。

## 从 alpha1 / alpha2 / alpha3 升级

1. 保留旧版配套安装包；可先在应用导出预设。
2. 在 Magisk 安装 `DSP-Audio-Driver-0.1.0-alpha4.zip`，然后重启。
3. 覆盖安装 `DSP-Audio-0.1.0-alpha5.apk`。包名 `com.dspfusion.android` 和签名不变，无需卸载或清除设置。
4. 原 JamesDSP、ViPER RE/Fork/AIDL 和 AML 模块继续禁用。

应用升级时将旧 ViPER 左右平衡迁移到输出控制；若新位置已有值则保留。旧 ViPER 音量、限制器、十段 EQ、扬声器优化和分段总开关设置被清理；导入旧预设也会迁移。其他效果参数保留。两段引擎接通，音效是否启用由各项开关和底部总开关共同决定，旧的分段禁用值不再生效。

## 首次安装及回退

首次安装需先禁用旧 JamesDSP、ViPER 和 AML 模块并重启，再安装本模块、重启、安装 APK。模块 ID 仍为 `dsp_fusion`，库仍为 `libdspfusion.so`，只是显示名称改为“DSP音效”。安装器仅修改 Magisk 模块中的配置副本。

回退至 alpha3 应同时恢复旧 APK 和旧驱动；应用版本降级可能需要先导出设置再卸载。回退至原 JamesDSP/Viper：禁用本模块，重新启用原模块并重启，安装原应用和导入原预设。

## alpha5 界面变化

所有音效卡片冷启动默认折叠，点击标题仅展开或收起，只有右侧开关启用或关闭音效；展开状态与音效参数分离，旋转时保留当前展开状态。效果关闭时也可预先调节参数。MSEB 的左减右加按钮每次改变 1，到当前范围边界停止；双击滑杆归零。左右平衡支持双击归零。活动设备配置移入输出固定卡片，保留设备识别和原配置菜单。ViPER 统一为独立带图标卡片，采用原 DSP 的 Material 控件与颜色。

这次更名为 MSEB 仅涉及名称与操作方式，未改动滤波、动态处理或参数映射，不声称与海贝算法完全相同。

## 沿用的 alpha4 驱动行为

| 项目 | alpha4 行为 |
|---|---|
| 音频块 | 修复 960 帧回调被拆分后卷积/交叉反馈反复重置的问题，保持连续流的滤波状态。 |
| 脉冲响应 | 保留 WAV/IRS 导入；上传每个分片检查返回值，失败时不提交文件哈希并旁路卷积，避免半份数据生效。 |
| 交叉反馈 | 修正默认档初始化错用滤波器的问题，验证六种模式跨块处理。 |
| 模拟处理 | AnalogX 不再在模式切换时强制插入 250ms 静音；保留实际模拟算法。 |
| 输出 | 固定顶部保留 James 阈值/释放/后增益；左右平衡位于整条音效链末端，-100 最左、+100 最右。 |
| 删除项 | ViPER 的输出音量、末级限制器、十段 EQ、扬声器优化从控制及算法代码移除；James 原有输出限制器保留。 |
| 单项开关 | 不再有 James/ViPER 分段总开关，底部电源键控制整体，各项效果开关仍可独立调整。 |
| 听感调音 | 默认折叠，可保持效果开启时收起界面；范围为横向 ±20/±40/±100 三档。 |
| 图标和名称 | 启动器名称为“dsp音效”，页头“DSP音效”，图标资源固定黑白，不提供系统着色的 monochrome 图层。 |

删除 ViPER 限制器及其缓存延迟后，旧参数相同也可能产生不同电平与听感；用保留的 James 输出控制调节整体电平。海贝式参数仍为独立实现的听感近似，不保证相同整数等于海贝原声。

“参数均衡器”是本轮对原任意响应均衡器的名称调整，没有新增每频段独立 Q 控制。VDC/卷积仍共用 James 的文件入口，ViPER RE 上游未完成的独立 AGC/FET/VHE 不提供无效开关。

支持 Android 8+/ARM64/ARMv7。真实 USB 独占、直通和不同 AIDL/HAL 路由仍需在具体设备上确认；本轮按使用者自行安装、试听的安排提供配套包，自动测试范围见对应发布说明。
