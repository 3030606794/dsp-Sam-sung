# DSP音效 0.1.0-alpha8：升级与兼容性

## 安装和升级

**已经安装 alpha7 协议 4 驱动：只需覆盖安装 `DSP-Audio-0.1.0-alpha8.apk`，无需重刷驱动或重启。** 本次修改 Q/BW 和步长控件、显示设置与频响图标记，不改变 DSP 算法、音频参数范围或驱动协议。alpha7 与 alpha8 驱动均使用协议 4，可供 alpha7/alpha8 APK 使用。

首次安装或从 alpha6 及更早版本升级时，需要更新驱动；alpha6 使用协议 3，alpha4/alpha5 使用协议 2，不能与 alpha8 APK 混用。

1. 在 Magisk 安装 `DSP-Audio-Driver-0.1.0-alpha8.zip`，然后重启；已有 alpha7 驱动可跳过此步。
2. 覆盖安装 `DSP-Audio-0.1.0-alpha8.apk`。包名 `com.dspfusion.android`、签名、模块 ID `dsp_fusion` 不变，无需卸载或清除设置。
3. 原 JamesDSP、ViPER RE/Fork/AIDL、AML 模块继续禁用。融合模块提供一个公开音效实例和一份 `libdspfusion.so`。

首次安装也需先禁用上述独立模块并重启。安装器仅修改 Magisk 模块中的配置副本。支持 Android 8+、ARM64/ARMv7，需 root。

## 参数均衡器与旧数据

最多 170 个双声道共用的二阶滤波段。频率 20–20000 Hz，Q 为 0.1–100；峰值/低架/高架增益为 ±100 dB。低通、高通、带阻、带通不使用增益参数；带通中心峰值为 0 dB。

均衡器设置使用滑杆与可手动输入的右侧数值框：频段数量 1–170，增益滑块步长 0.01–2 dB，增益范围 1–100 dB（图表和滑杆显示 ±对应值），Q/BW 滑块步长 0.01–100，频率滑块步长 1–1000 Hz。Q/BW 和频率的新设置均为步长，不改变频段实际 Q 或频率的允许范围。缩小增益显示范围不裁剪已有增益。

可显示每段 Q/BW 和频率滑杆，两侧减号、加号按设置的步长调节。每段记住 Q/BW 显示方式，精调窗口确定后主界面继续使用相同标签、数值和滑杆。编辑、展开、显示设置均不自动启用音效，主页右侧开关独立控制。

新默认频段按数量在 20–20000 Hz 对数均分。数量为 1 时使用几何中心频率；数量大于 1 时首末段为 20/20000 Hz。更改设置中的总数量会重分布全部频率，保留已有段的 ID、类型、增益、Q 和启用状态；减少数量前确认。单段复制、添加、删除不强制改写其余段。已有 alpha6 或手动调音不自动重排，可使用“重新分布频率”明确执行。

顶部固定曲线左右各留 2dp，线宽为 1.25dp，按 48 kHz 显示参数滤波器的合成幅频响应，不包含后续 MSEB、ViPER、动态处理或限制器。红色小圆点及文字实时显示当前频段的频率、增益设定值；无增益类型显示 0 dB。红点不表示多段叠加后的增益，超出图表增益范围时点停在边缘、标签保留真实数值，边界标签会避让。

BW 以 octave 表示，按 48 kHz 数字频率校正换算成 Q 后保存；峰值/带阻/带通可用，其他类型使用 Q。切换 Q/BW 显示不改变原始滤波参数；增大 BW 会变宽，增大 Q 会变窄。驱动按实际采样率重新计算，频率达到或超过 Nyquist 的段暂时旁路，不改写保存值。

旧曲线/AutoEQ 功能已删除，历史字符串保留在配置中作为备份，不再执行，也不误转换成峰值滤波器。已有新 PEQ 数据继续使用；仅有历史曲线的配置进入默认零增益 PEQ。新数据与显示开关仍保存在 `dsp_graphiceq`，随设备配置与预设保存。旧配置缺少新增字段时，Q/BW 步长默认为 0.01、频率步长默认为 1 Hz；原有频率、增益、Q 和 Q/BW 模式保留。

新导出预设要求应用版本码至少 1008（alpha8）。alpha7 不支持新的连续增益步长/范围，且不认识新增步长设置，不能无损导入 alpha8 预设；最低版本检查会阻止旧应用导入。旧预设仍可导入 alpha8；导入缺少 PEQ 数据的预设会回到默认 bank。

## 处理与验证范围

处理顺序为 **PEQ → JamesDSP → MSEB → ViPER → 左右平衡**，不占用 DDC、卷积或 LiveProg 通道。James 输出控制继续调节限制器阈值、释放与后增益。±100 dB 是单段滤波参数范围，最终响度受后续限制器影响；超出内部数值表达能力的极端多段叠加会进行饱和保护，不回退干声。

保留此前连续音频块、卷积分片校验、交叉馈送、AnalogX 模式切换修复，以及 MSEB ±1/双击归零、独立展开启用、ViPER 图标和固定输出卡。MSEB 是独立实现的海贝式听感近似；Neutron 仅用于交互参考，没有使用其私有音频代码或图像。

170 段是支持上限，开销随有效滤波段数增加；零增益峰值/架式段跳过运算。自动测试覆盖模型、带宽切换、界面交互、极值音频、参数更新和连续处理；本次 alpha8 构建、回归与安装包验证结果待验证完成后记录。主机性能不能代表手机实时负载；设备试听、USB 独占、直通及具体 AIDL/HAL 路由仍由用户安装后确认。

## 回退

回退 alpha7 不需更换协议 4 驱动，但 alpha7 无法读取任意连续增益步长/范围，也无法保留新增步长设置；应恢复升级前由 alpha7 导出的预设，不能导入 alpha8 新预设。回退 alpha6 时同时恢复 alpha6 驱动并重启，再恢复 alpha6 APK；其 Q30/±24 dB 范围无法表达本版极值。回退旧版前另存预设，Android 降级安装可能需要卸载。回退原 JamesDSP/ViPER 时禁用融合模块，重新启用原模块并重启，再使用原应用。
