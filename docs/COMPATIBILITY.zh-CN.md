# DSP音效 0.1.0-alpha12：升级与兼容性

## 安装

本版 APK versionCode 1012，驱动协议仍为 5。修复 alpha11 内置可编程 DSP 中文参数解析在 Android 上闪退的问题。本轮未改原生音频实现；已安装 alpha10 或 alpha11 驱动时，只需覆盖安装 `DSP-Audio-0.1.0-alpha12.apk`。随附 alpha12 驱动与 alpha10 的音频实现一致。alpha9 驱动可处理音效，但首页采样率及处理活动查询需 alpha10 或更新驱动。包名、签名和模块 ID `dsp_fusion` 不变，无需卸载或清除数据。

alpha7/alpha8 协议 4、alpha6 协议 3 和更早驱动不可与本版 APK 混用。原 JamesDSP、ViPER RE/Fork/AIDL、AML 模块保持禁用。支持 Android 8+、ARM64/ARMv7，需 root；用户自行安装。

## 均衡器

最多 170 段，支持重复频率、七种滤波类型及 Q/BW 两种显示。实际范围为频率 20–20000 Hz、Q 0.1–100、增益 ±100 dB，另允许 0 Hz 作为未设置标记。新段为峰值、0 Hz、0 dB、Q 0.5；0 Hz 不参与滤波，传给驱动时使用禁用的 20 Hz 占位段，不改写启用状态。

底部为等宽的设置、重置、编辑、预设、参数设置五按钮。图下方前/后添加按钮点按增加一段，双击跳到顶部/最后一段，长按可选 5、10、15、20 或自定义；容量不足拒绝本次添加，不部分添加。设置改变总数量时仍可选择前/后增删及是否重分布。默认保留原频率、ID 和各项参数；仅显式重分布时按 20–20000 Hz 对数分配。

步长只用于加减按钮：增益步长 0.01–2 dB，Q/BW 步长 0.01–100，频率步长 1–1000 Hz。拖动精度为增益 0.01 dB、Q/BW 0.001、频率 1 Hz。增益滑杆正值红色、负值蓝色、零值恢复主题色。点击数值直接打开并选中对应精调输入框。

增益范围 1–100 dB 同时限制滑杆、按钮及手动输入。Q 范围上限为 0.1–100，同样限制三种输入途径；BW 从同一 Q 范围换算，边界随频率更新。缩小设置不自动裁剪已存参数；精调确认须满足当前范围。Q/BW 模式切换保持实际 Q，所有滤波器均可切换；实际滤波形状仍由所选类型决定。旧配置未保存 qRange 时默认 100。

七类滤波器都支持增益。峰值/架式保留其增益定义；低通、高通、带阻、带通在原滤波输出上施加增益，0 dB 仍执行滤波。编辑、应用预设和重置均不自动开启音效。

重置菜单包含 Q、频率、增益、滤波器类型及全部重置，并提供带确认的“按当前数量重新分布 20 Hz–20 kHz”入口。Q 恢复约 0.7071（若设置上限更低则取上限），频率按现有数量对数均分，增益归零，滤波器类型恢复峰值。全部重置包含上述四项；保留数量、ID、启用状态与显示设置。

## 图表

右上角切换固定或随列表滚动。定位图标和 0 Hz 的 ! 提示在卡片标题行中部。定位或调节会显示当前频段中心点及 XY 辅助线，两轴投影端点有红点；标签为频率、增益和当前 Q 或 BW。拖动中持续显示，结束后 2 秒隐藏。曲线/辅助线宽 1.25dp，网格 0.5dp，中心点 3dp、标签 9sp。

图表使用 48 kHz 参考采样率计算 PEQ 合成响应，不含 MSEB、ViPER、限制器。中心点表示频段设定，不代表多段合成增益。计算复用未变化频段、合并请求；标记直接跟随最新参数。手机帧率仍需实机验收。

## 驱动与采样率

处理顺序为 PEQ → JamesDSP → MSEB → ViPER → 左右平衡。驱动支持 8–192 kHz、双声道同输入/输出率。系统音频路径决定实际配置，本应用没有强制改变其他播放器 USB 输出采样率的接口。

alpha10 增加可选只读宿主采样率及处理计数查询，协议仍为 5；首页显示实际驱动状态，不将 James 内部采样率或图表 48 kHz 参考值当作真实宿主率。旧驱动查询不支持时显示未知，不编造数字。音效宿主采样率不保证等于 DAC 最终输出率，系统后级仍可能重采样；USB 独占、直通或硬件 offload 可能绕过系统音效。

±100 dB 是滤波参数范围，最终输出受限制器影响；极端多段组合有数值保护。170 段开销随有效滤波段数增加，零增益峰值/架式段可跳过。MSEB 是独立的听感近似，Neutron 仅作交互参考。

## 预设与旧数据

PEQ 参数对象保持 schema 2、独立收藏格式 version 1、驱动二进制包 schema 1，三个版本互相独立。原有 schema 1 隐藏无效增益按 alpha9 规则迁移为 0 dB，其他参数保留。新全局预设最低版本码 1010，防止旧应用忽略 Q 范围；旧预设仍可导入，缺少 PEQ 数据时使用默认 bank。

独立 PEQ 收藏最多 20 个，可保存、应用、改名、覆盖、删除、导入及单项/全部导出，保存于私有 `peq-presets.json`，不会随设备或全局预设替换。UTF-8 JSON 为本应用格式，不保证兼容 Neutron。导入整体校验容量、类型和数值，重名加序号，不覆盖已有收藏；详情见 [PEQ 预设格式](PEQ-PRESETS.zh-CN.md)。

回退 alpha9 将丢失新 Q 范围语义；更早版本还可能不支持 schema 2 和协议 5。回退前请另存预设，恢复匹配 APK/驱动并重启，勿使用卸载清数据作为常规升级步骤。

## alpha11 界面与批量操作

精调 Q/BW 统一显示三位小数，切换保留内部完整 Q，不将显示舍入值反复写回。新增批量 Q、BW 和滤波器类型设置；批量 BW 按各频段频率换算，同一输入须同时满足所有频段的 Q 上限，失败时整组保持原状。若无共同可输入 BW 范围，可先扩大 Q 范围或使用批量 Q。

卡片的频率、Q/BW 仅在对应滑杆隐藏时补充到标题下，滑杆都开启则标题仅显示“序号 • 类型”；点击类型直接选滤波器。首页增加实际系统栏及刘海留边。

内置实时 DSP 脚本补充中文显示；动态低音默认及重置值为 5%。只匹配旧内置原文迁移未修改脚本，用户保存过的参数和自定义脚本不自动覆盖。

## alpha12 多选编辑

点“编辑”后该按钮原位变“删除”，“设置”禁用；选中有效目标后“重置、预设、参数设置”变色启用。编辑区提供全选、取消全选和完成，返回键也退出编辑。编辑模式按频段 ID 保存选择，点击卡片空白切换并高亮；控件点击仍执行各自操作。操作范围为选中或未选中，默认选中。Q/BW/类型批量设置、各项重置、重新分布及删除只作用于目标频段，其他频段和总设置保持不变。BW 范围只根据目标频段计算。删除前确认，至少保留 1 段，数量同步到设置（1–170）及添加入口。全选允许批量设置、重置和保存；删除全部时提示并拒绝。

预设的保存和覆盖在编辑模式中仅保存当前范围，列表中的应用预设仍沿用整份预设替换当前 bank 的行为。退出编辑恢复对全部频段操作。新增频段不自动加入选择；外部配置替换会关闭失效的编辑弹窗。
