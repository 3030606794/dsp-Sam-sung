DDC 耳机响应校正 — 专业增强 ui38 / 1051

一、原文件与兼容行为
本轮增强原“DDC 耳机响应校正”模块，保留原 VDC 文件选择、模块电源、默认声音及开关折叠规则；三个随附原文件的原始字节不变。
专业总开关、校正比例、个人补偿、四个补偿滤波器、双耳微调、前级衰减、预测静态余量、输出增益、电平与响应图均默认关闭。双耳“联动”默认选中，但双耳组默认关闭，不因此增加任何处理。
专业关闭时恢复当前原文件的 DDC 声音。专业开启但所有新增声音分组关闭时仍使用当前原文件校正，不自动套用系统方案。与耳机交叉馈送、六预设交叉馈送、两种混响、音色调节及其他模块分别保存和处理；同时开启多个模块仍按音频链叠加。
若新选择的文件损坏、尚未确认或仍在准备中，关闭专业也会立即针对当前实际有效的旧基础撤销附加处理，不启用未确认的新文件。驱动提供原子“恢复原 DDC”命令 196652（载荷为 0）：仅恢复已生效基础的原版声音，保留有效文件、电源与保存的专业请求，并取消临时试听及待接管候选；不通过伪造默认文件或旧 SHA 配置来完成关专业。
VDC 是数字滤波系数文档，不包含完整的耳机实测曲线、目标曲线或可靠的原参数描述。不能把任意 VDC 反解成准确的频率、增益和 Q。本轮个人补偿是独立的后级滤波，不改写原 VDC。

二、校正比例与个人补偿
校正比例 0.0–100.0%，精度 0.1%，默认 100.0%。0% 旁路本模块的原 VDC 滤波，100% 完整使用当前文件。若其他专业组仍开启，0% 时这些补偿、双耳电平与输出仍可生效；它不等于关闭整个模块。
中间比例对模块输入与校正声作线性混合。由于滤波相位改变，50% 不等于原曲线各频点 dB 值简单减半；实际响应按复数滤波响应和真实混合位置计算。
个人补偿组含低频架式、高频架式、两路峰式滤波器；四路各有独立开关，默认均关闭。
低频架式：20–1000 Hz，默认 120 Hz；增益 −12.0–12.0 dB，默认 0.0；坡度 S 0.250–1.000，默认 1.000。
高频架式：1000–20000 Hz，默认 8000 Hz；增益 −12.0–12.0 dB，默认 0.0；坡度 S 0.250–1.000，默认 1.000。
峰式 1：20–20000 Hz，默认 1000 Hz；增益 −12.0–12.0 dB，默认 0.0；Q 0.25–10.00，默认 1.00。
峰式 2：20–20000 Hz，默认 6000 Hz；增益 −12.0–12.0 dB，默认 0.0；Q 0.25–10.00，默认 1.00。
频率精度 1 Hz、增益 0.1 dB、Q 0.01、架式 S 0.001。S 是所用架式滤波公式的形状参数，不标成固定 dB/oct。峰式两路独立，不要求频率升序。
频率请求按实际内部采样率派生安全频率，保存的请求不变；诊断显示实际作用频率。采样率恢复后重新计算，不将低采样率下限幅永久写入预设。
补偿增益为 0 dB 时该路没有额外音色作用，仅改频率、Q 或 S 可能听不出差别。

三、双耳微调
双耳组默认关闭；默认联动。每耳校正比例权重 0.0–100.0%，精度 0.1%，默认 100.0%；每耳电平 −12.0–12.0 dB，精度 0.1 dB，默认 0.0 dB。
最终每耳 VDC 比例 = 全局校正比例 × 该耳权重；对应分组关闭时采用 100%。例如全局 80%、左耳 75%，实际左耳原文件混合比例为 60%。
联动时采用左耳权重与左耳电平作用于两耳，右耳参数置灰；右耳独立保存值保留，不被左耳更新覆写。解除联动后恢复右耳保存值。双耳组关闭时恢复两耳原校正和 0 dB 额外电平。
本轮左右共用同一个 VDC 原文件，未提供左右不同文件或听力测量自动匹配。“双耳归中”是联动中性方案，不自动识别耳机偏差或听力差异。

四、余量与输出
前级衰减 −48.0–0.0 dB，精度 0.1 dB，默认 0.0 dB，分组默认关闭。
输出增益 −24.0–12.0 dB，精度 0.1 dB，默认 0.0 dB，分组默认关闭。正输出增益可能增加超限风险。
预测静态余量独立默认关闭；安全边际 0.0–12.0 dB，精度 0.1 dB，默认 1.0 dB。启用后根据当前原校正、实际干湿、额外补偿、双耳电平、前级与输出的最终静态响应估计需要的共同衰减，只衰减不增益。
处理位置：本模块输入 → 手动和自动前级（同时作用于干湿两路）→ 原 VDC → 原声/校正声混合 → 个人补偿 → 双耳电平 → 输出增益。
自动余量是静态预测，不是实时音量匹配、真峰值限制器或最终不削波保证；有限频率预测和实际节目瞬态存在差异。后续模块还可能改变峰值。界面显示预测静态峰值及实际自动衰减，不把衰减误报成滤波未生效。

五、输入、加减、置灰与复位
20 个数值项均支持滑杆、直接输入、加减和单项复位。专业或所属分组关闭时参数置灰、保存请求保留，重新开启恢复；已打开输入框也不能绕过禁用状态提交。
原文件选择仍可操作，本轮没有把文件选择灰掉。专业关闭恢复当前原文件声音；模块关闭保留原折叠规则。
单项复位恢复相对于当前原文件的中性基础：比例和双耳权重 100%、额外增益/前级/输出 0 dB、频率/Q/S 对应上述默认值、安全边际 1 dB。复位不清空、不替换、不改写原文件，也不修改其他模块或独立收藏。
改变音频参数会停止当前试听与匹配，保留同文件 A/B 快照供重新比较；切文件、关闭专业/模块、折叠/离开页面、暂停或音频会话/采样率改变时清除临时试听和 A/B，避免旧状态跨文件或会话生效。

六、独立预设
提供六个主动应用的系统听感方向，均保留当前原 VDC 文件，不改变模块电源：
1. 原文件校正：关闭专业附加层，恢复当前原文件声音。
2. 轻校正：使用 75% 原文件混合。
3. 温暖柔润：120 Hz 低架 +1.5 dB、8000 Hz 高架 −1.0 dB，开启预测静态余量。
4. 清亮人声：1800 Hz 峰式 +1.0 dB、Q 0.80，10000 Hz 高架 +0.8 dB，开启预测静态余量；不识别或分离人声。
5. 柔和耐听：6000 Hz 峰式 −1.5 dB、Q 1.00。
6. 双耳归中：双耳联动，权重各 100%、额外电平 0 dB。
这些方案重建附加调节，是听感起点，不是 Harman、Diffuse Field 等测量目标，也不是特定耳机保证校正。
个人收藏独立文件 ddc-favorites-v1.json，最多 20 条、总文档不超过 8 MiB。保存、覆盖、改名、删除及导入导出均可用。名称 1–40 字符，不允许控制字符、无效 Unicode 或重复名称。
每条收藏同时保存当前 VDC 原始文本、SHA-256 内容指纹、原路径与显示名称，以及全部专业参数和分组；不保存模块电源、临时试听、A/B 快照、匹配或测量结果。独立库不随设备配置替换。
应用收藏时，原文件存在且内容指纹一致则复用原路径。原文件缺失或同名内容改变时明确提示，并从内嵌原文还原为 DDC/收藏-<SHA256>.vdc 独立副本；同名副本已被改变或存在中断写入文件时追加编号，不覆盖原文件或随附内置文件。导入路径只作为显示元数据，不决定写入位置。
预设导入严格检查模块/版本/单位、未知或缺失字段、重复字段（含转义后的重复名称）、类型、全部关闭组的范围、VDC 内容及 SHA 指纹；任一条无效则整次拒绝。库写入使用 AtomicFile；部分写入失败保留上一次完整库。
合法单个 VDC 最大 256 KiB，多个大文件收藏可能先达到 8 MiB 库限制；这时保存/导入给出容量错误，不部分写入。

七、响应与试听诊断
静态响应图显示“当前实际原文件响应”“左耳最终静态响应”“右耳最终静态响应”。最终图包含干湿相位组合、个人补偿、双耳电平、手动/自动前级及输出。
图表是驱动按实际系数计算的算法响应，不是耳机实测频响，也不表示已达到某条耳机目标曲线。图表对应主处理配置，不将临时原声/差分/A/B 试听误标成主校正曲线。
电平显示当前音频块的输入/输出左右峰值与 RMS，以及超限帧数；不是 LUFS、真峰值、长期累计或 2 秒均值。
试听包括正常、原声、效果、差分与 A/B 两个独立参数快照。首轮 A/B 限定同一个当前 VDC 文件，不支持跨文件快照；切文件立即停止并清除旧快照。
电平匹配使用同一输入，先预热两个快照，再在明确启动测量时累计固定 2 秒 RMS，得到只衰减、不增益的固定匹配。普通 A/B 不自动持续测量。过静音或未完成时不宣称匹配就绪。
匹配用于减少响度差对试听的干扰，不是感知响度/LUFS 校准。差分声可能很小或相消，不能单凭差分音量判断校正优劣。
运行状态区分已接受文件与正在实际播放的文件；切换需要预热和平滑交接时显示准备状态，不把尚未接管的旧音频误报成新文件已完全生效。
候选内核的预热和平滑交接不等于整个控制准备过程都保证旧处理声音连续。现有 Fusion 在准备文件、设计补偿或计算预测余量时需要占用处理锁；锁忙时音频会临时使用原声旁路，准备结束后再按有效配置处理。大文件、较多滤波节或频繁调整时，应在目标手机验证准备时间、过渡与恢复表现；正式控制准备计时见本次原生日志，不用开发机结果代替真机表现。

八、文件校验、加载失败与采样率
VDC 最大 256 KiB。支持开头一个 UTF-8 BOM，原 SHA 包含其原始字节；正文必须为 ASCII。只允许 SR_44100 与 SR_48000 两段，各恰好出现一次，顺序可交换，每段 1–128 组五系数且两段数量相同。
系数接受带符号十进制及科学计数法，单 token 不超过 127 ASCII 字符，必须有限且绝对值不超过 1e12；拒绝 NaN、Infinity、十六进制、嵌入 NUL、注释、未知字段、重复字段、缺项与多余内容。
按 VDC 正反馈符号验证二阶极点：|a2|≤1−1e−12，1−a1−a2≥1e−12，1+a1−a2≥1e−12。所有滤波节及两个采样率均检查。
先完整验证和准备候选文件，成功才确认装载。解析、内存准备、上传或提交失败时保留上一个有效校正与播放配置，明确报错；不会先清空旧配置，也不会把失败报告成成功。用户主动关模块仍立即关断有效处理。
App 文件校验通过只表示文法、大小、数量、有限系数与单节极点有效，不保证整个串联滤波在浮点数范围内可用。驱动还以控制线程上的单位冲激和频率响应检查串联数值溢出；准备拒绝时保留旧配置并显示装载失败，不能把 App 校验成功当作已生效。
同名文件内容改变使用 SHA-256 身份识别，不能只凭文件名或旧 CRC 宣称已装载。响应和状态采用同一时期与采样率快照，旧会话读数不能覆盖新配置。
保留原 44.1/48 kHz VDC 分支与现有主机高采样率的重采样路径；内部采样率变化时重新选择有效系数、刷新补偿与响应并清除临时试听，不因文件文字相同跳过刷新。没有有效分支的非标准内部采样率安全旁路并显示状态，不继续使用旧系数。
