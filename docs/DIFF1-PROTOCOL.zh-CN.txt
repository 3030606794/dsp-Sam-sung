声道差分延时：第一轮协议与声音边界
协议版本仍为5；新增能力位1024；本包能力合计2047。

一、持久参数
SET 65632，严格7个int32，依次：
0 模式：0原版兼容，1精密；默认0。
1 精密时间：0..2000，单位0.01ms，默认500（5.00ms）。
2 延迟声道：0右，1左；默认0。另一声道不增加声道差分延时。
3 混合：0..1000，单位0.1%，默认1000（100%）。
4 选频开关：0/1，默认0。
5 选频下限：40..2000Hz，默认150Hz。
6 选频上限：2000..20000Hz，默认12000Hz。必须下限<上限。
包长度、数值范围、频率顺序均完整验证后才更新，失败没有部分写入。

65557仍是模块独立开关。65558仍为旧延时，单位0.01ms，合法0..5000（0..50ms）。
旧界面原有1..20ms/1ms步长及默认5ms仍可使用。原版模式始终右侧、100%混合、全频处理；忽略65632中的其他专业字段。
精密模式和旧延时分别保存。精密模式下更新65558只保存旧值，不重置当前精密音频。
旧模式每次实际改变65558仍按旧式float毫秒→double运算→uint32截断，并重置历史。重复相同命令不重置。
旧模式启动、静态处理、旧延时改值和Reset可与ef77b01原始实现逐样本对照；精密模式热调及两模式切换采用新平滑行为，不声称热切换等同旧Reset静默。

二、处理结构和真实延时
原版：Lout[n]=L[n]；Rout[n]=R[n-floor(Fs*delayMs/1000)]。
精密全频：只对选定声道处理 y=(1-mix)*x+mix*D(x)，D为真实两点线性分数延时。
0.01ms是控制刻度，不再截断为整数样本。两点插值不是理想全通延时：非整数延时在高频存在幅度下降，不能宣传为无幅相误差。
精密混合0%和0ms均可取消全频声道差分效果。

选频开启采用有限长对称Fejer/Bartlett窗FIR：
M=round(Fs*0.020)，长度N=2*M+1，即约40ms的物理窗长。
理想对称通带的sinc系数乘1-|k|/(M+1)，不做峰值或DC二次归一化。
去除公共线性相位后，B(w)是0/1频率掩模与非负Fejer核的卷积，理论0<=B<=1；有限精度存在数值误差。
选定声道传递函数：H=z^-M + mix*(D-1)*B；另一声道为z^-M。
因此保留互补分量，并非从原声减普通IIR带通。稳定配置下两点分数延时的幅度不大于1，结合0<=B<=1，选频支路不会因分频边缘产生额外稳态增益。
这是平滑选择频段，不是砖墙分频；频段外仍存在有限窗泄漏。特别40Hz附近不能解释成40Hz以下完全原声、以上立刻全效果。频率值是目标边界，并非实测-3dB硬截止。
滤波目标裁到1..Fs/2-100Hz，运行读数返回裁限后的目标Hz。

长FIR使用均匀分区FFT overlap-save，FFT分块P为不小于Fs/375的最小2次幂，FFT长2P。
公共参考延时为M+P个样本；在48kHz为1088样本≈22.667ms，在192kHz为4352样本≈22.667ms，在8kHz为192样本=24ms。
只有精密选频开启才引入该公共延时。0ms或0%混合仍保留已启用选频的公共延时；关闭选频后公共延时回到0。
该值是共同参考/群延时，不能据此声称任意频率的选定声道具有单一固定总群延时；FIR有有限前后振铃。
差分延时与公共延时必须分别显示。

三、连续调节与实时资源
新配置采用约15ms的旧/新完整处理分支交叉淡变。延时读点固定，不让读点持续扫动产生滑音。
快速多次编辑在当前过渡完成后采用最新待处理配置；重复同包不重新启动过渡。
方向、混合、频段、模式变化同样平滑。公共延时不同的分支交叉淡变期间可能短暂相消，不能把过渡过程标成单一实际延时。
原始历史和分区FFT输入历史持续保留，新FIR可读取已存在历史；不因滑块拖动重置音频历史。
处理回调使用已分配环形缓冲、FFT历史及工作区，不分配内存。
PrepareAdvanced在控制路径准备不可变FIR频域计划；Fusion在音频总锁外执行准备。
ApplyPrepared在短提交锁内只交换待用计划指针和7项设置；旧计划由调用者在锁外释放。采样率变化导致准备快照失配时拒绝提交并允许重试。
并发参数请求以最新有效请求为准；重复当前参数也会撤销更早仍在准备的不同参数。迟到准备只确认已被更新请求取代，不覆盖新配置。私有提交命令0x44494650不对外开放。
配置/Reset本身会清历史并按采样率准备处理，不等同于连续拖动参数。

四、临时试听
SET 65633严格单个int32：0正常，1本模块旁路，2处理后单声道。
旁路输出本模块入口原声，不带本模块公共延时；单声道为处理后(L+R)/2，左右相同，不额外加增益。
正常/旁路/单声道试听之间约15ms线性渐变，随后精确到达目标试听。旁路与选频正常输出的公共延时不同，切换时不能假定样本对齐。
请求0始终退出。非0请求仅当与最后一次请求不同且模块开启时进入；同值陈旧包不能恢复被取消的试听。
模块关闭、主处理关闭、ViPER引擎关闭、Reset/重配置会取消实际试听并清运行读数，但保留最后请求锁存。再次启动必须显式0后重新选择，或选择不同非0模式。
试听不进入预设。先送配置，再确保65557开启，最后送试听请求，避免开启模块的Reset取消刚开始的试听。
内部65634仅清本模块运行状态；Fusion不向外开放该命令。

六、功能分工与限制
本效果位于立体声成像之后、ViPER混响之前。成像模块之前的相关度回收不能保护随后新增的声道差分延时。
本模块延迟整个左或右声道，单声道输入也可能变成左右不同；与仅处理Side且不从纯Mono制造Side的成像空间支路不同。
本模块不是HRTF，不模拟完整房间反射，也不承诺万能单声道安全。延时本身及干湿混合会产生频率相关的相消、声像偏移和折叠损失。
