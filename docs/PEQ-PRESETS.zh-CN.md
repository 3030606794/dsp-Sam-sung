# PEQ 预设收藏与 JSON 备份

参数均衡器底栏的“预设”提供独立收藏库，最多保存 20 个预设。每个预设保存全部频段，以及增益范围、按钮步长、滑杆显示和频响图固定偏好；不保存总音效开关，也不自动启用音效。

## 使用与存储

- “保存当前参数”创建新收藏，名称支持中文，去除两端空白后为 1–40 个字符；不能含换行或控制字符。手动保存、改名遇到同名会提示修改名称。
- 点击收藏可应用、改名、用当前参数覆盖、导出或删除。改名不改变收藏参数；覆盖和删除需要确认。删除收藏不改变当前均衡器参数。
- “导入 JSON”将预设加入库，不立即应用。导入先验证全部参数和剩余容量，任意一项非法或总数超过 20 时整次导入失败，不写入部分内容。重名自动添加 ` (2)`、` (3)` 等序号，必要时缩短原名称，不覆盖已有收藏。
- 单项导出和“导出全部”都由系统文件选择器指定位置。文件采用 UTF-8 JSON，可保存在外部位置备份或分享；空库无法导出。

收藏保存在应用私有目录中的 `peq-presets.json`，独立于当前设备配置和原有全局预设。切换设备、加载或导入全局预设不会替换收藏库；导出全局预设也不包含收藏库。清除应用数据或卸载前，请单独导出要保留的收藏。读写失败时保留原库并显示错误。

## 文件格式

这是 **dsp音效本应用的格式**，不保证直接导入 Neutron 或其他应用的预设。不要只修改其他格式文件的扩展名来导入。

| 字段 | 含义 |
| --- | --- |
| `format` | 固定字符串 `dsp-audio-peq-presets` |
| `version` | 数字 `1`，表示收藏文件格式版本 |
| `presets` | 包含 1–20 项的数组；单项导出仍使用数组 |
| `presets[].name` | 收藏名称 |
| `presets[].state` | 完整 PEQ 参数对象，新导出使用 `schema: 2` |

文件上限为 4 MiB，必须是有效 UTF-8。每项最多 170 个频段，增益为 −100 至 +100 dB，Q 为 0.1–100；有效频率为 20–20000 Hz，另允许 `0` 表示尚未设置的频段。0 Hz 不参与滤波，设为有效频率后才生效。未知类型、非法数值或无效参数结构会拒绝导入。

同一预设内的正频率不可重复，包括已关闭的频段；频率乘 1000 后四舍五入所得的整数必须不同。这个判定与传输的 0.001 Hz 精度一致，避免两个看似略有差异的数值送入驱动后成为同一频率。多个 0 Hz 占位段允许并存，界面显示“! 未设置”。不同收藏之间可以使用相同频率。外部文件中任何一项存在重复有效频率都会使整次导入失败。

以下是可导入的单项示例：

```json
{
  "format": "dsp-audio-peq-presets",
  "version": 1,
  "presets": [
    {
      "name": "人声示例",
      "state": {
        "schema": 2,
        "gainRange": 18,
        "gainStep": 0.1,
        "qStep": 0.01,
        "frequencyStep": 1,
        "pinResponse": true,
        "showQSlider": true,
        "showFrequencySlider": true,
        "bands": [
          {
            "id": "example-band-1",
            "type": "PEAK",
            "enabled": true,
            "frequency": 1000,
            "gain": 2,
            "q": 0.5,
            "qualityDisplay": "Q"
          }
        ]
      }
    }
  ]
}
```

频段类型为 `PEAK`、`LOW_SHELF`、`HIGH_SHELF`、`LOW_PASS`、`HIGH_PASS`、`NOTCH` 或 `BAND_PASS`。每个预设中的频段 `id` 必须唯一；收藏自身的本地 ID 不写入外部文件，导入时重新生成。`qualityDisplay` 为 `Q` 或 `BW`；BW 编辑适用于峰值、带阻和带通。

收藏格式 `version: 1`、参数对象 `schema: 2` 和驱动协议 `5` 是独立版本。收藏可读取旧参数对象 schema 1，并按 alpha9 规则将旧通带/阻带类型未生效的隐藏增益迁移为 0 dB；后续导出使用 schema 2。原有设备/全局预设文件请继续从对应入口导入，不使用本收藏入口。

升级前已有的本地收藏采用兼容读取：重复正频率保留首段，其余重复段仅将频率改为 0 Hz，保留所有其他参数，读取不回写原文件。此兼容处理不用于新导入的外部收藏文件；请先修正外部文件中的重复频率再导入。
