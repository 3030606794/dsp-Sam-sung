可编程 DSP 修复说明（UI38-fix1 / 1052）
基线：UI38，2cdf690556c7e208477ab6a2ea4b1c102ad2d3f5。

一、问题确认
1. APK 参数写回固定两位小数，滑杆未完整使用声明步长；0.001 等参数会丢精度。
2. 参数页通过 EelParser 保存原文件，再广播重载，导致脚本初始化及延迟、混响状态重建。
3. 驱动先清理旧 VM 再编译，编译失败会失去旧脚本；上传入口忽略编译结果，APK仍提交新hash。
4. 内部处理采样率变化仅更新 srate 变量，没有重新计算初始化阶段派生的系数。

二、修复行为
APK 参数按脚本声明步长量化，保留相应小数精度；参数独立保存在应用偏好设置中，
以脚本路径与源内容标识隔离。参数页不再改写 EEL 文件，也不通过重载调整参数。
同一有效脚本的参数通过专用命令更新已有变量，执行可选 @slider 参数更新段，
保留 @sample 的运行状态和缓冲。脚本源代码的主动编辑、切换和采样率变化仍需初始化。

内置40份原始脚本保留。22份带参数内置脚本提供单独的运行时适配，覆盖106个参数；
只对代码指纹匹配的内置脚本使用适配，保留原文件参数值。适配将系数、增益、延迟长度
等派生计算放入 @slider，缓冲分配、位置和历史状态初始化留在 @init。

新脚本在候选 VM 中先编译全部区段，成功后初始化并接管；任一区段编译失败保留
原有效 VM 与运行状态，返回失败状态，阻止失败脚本的hash提交。
实际内部处理采样率变化重新准备脚本，并恢复已设置的参数后执行 @slider。
采样率重建失败时保留源码与参数供重试，旧采样率的脚本暂时旁路，避免沿用错误系数。
三星 legacy/HIDL 协议仍为5，扩展能力由3增至7（新增可编程DSP位4）。

三、自定义脚本
格式为 @init、可选 @slider、@sample，各标记独占一行。
@init：变量默认值、函数声明、分配缓冲、初始化历史。
@slider：依赖参数的系数/增益/延迟长度更新，避免清缓冲和重置历史。
@sample：逐采样处理。
没有 @slider 的旧自定义脚本仍可加载，参数变量可以直接更新；如果参数只在 @init
中用于计算派生值，需由作者把相应更新计算移至 @slider，才能实现有状态的即时调参。
应用不会推断任意自定义程序的副作用并自动重跑其初始化。
脚本自行在 @slider 中清理状态时，其行为由脚本决定。
旧STFT Filter内置脚本声明的“Hz”实际被程序用作FFT bin；本次保留默认100..480
区间的声音语义，只限制排序后的bin位于0..fftsize/2，以避免参数越过FFT工作区。
Time adjustment 的负延迟仍依赖宿主PDC能力，不表示驱动能真正播放未来采样。

四、接口
GET 131234：扩展能力，位4表示本修复所需接口。
SET 196656：72字节，前64字节为NUL结尾、零填充的ASCII变量名，后8字节为小端double。
只允许已有变量，拒绝srate/spl0/spl1、无效标识符和非有限数值。
GET 131241：最近编译结果，1成功；0缺init；-1 init语法；-2缺sample；-3 sample语法；
-5内存；-6 slider语法；-7区段无效、重复或传输无效。参数setter内部错误-4表示参数无效。
原10010脚本提交在失败时返回错误，25002不接受失败编译后的hash提交。
